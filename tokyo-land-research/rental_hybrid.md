# 一階を貸す前提で「事業として」家を買えるか（rental_hybrid.md）

問い：**一階を賃貸に回すことを前提に、事業として家を買えないか。**

結論から書く。**買える。ただし「事業として」買うと成立しない。**
成立するのは「住宅ローンで自宅として買い、その一部を貸す」＝**賃貸併用住宅**の形だけである。
この一行の意味を分解するのが本書。

---

## 0. 先に結論だけ

| 問い | 答え |
|---|---|
| 1階を貸す家を買えるか | 買える。賃貸併用住宅として一般的な形 |
| 事業用ローン／法人で買えるか | 買えるが、23区の価格で**1戸だけ貸す規模では返済が埋まらない**（下記2章） |
| 儲かるか | 儲からない。**住居費が下がる**だけ。そこを取り違えると全部の判断を間違える |
| 税務上「事業」か | 1戸なら不動産所得だが**事業的規模（5棟10室）ではない**。青色申告特別控除は最大10万円 |
| **自分のローンで都心に届かないとき、1階賃貸で届くか** | **届かない。**賃料を年収算入しても増える枠は+400〜900万で、賃貸化工事費550〜1,000万にほぼ相殺される（→3章） |
| **ローンを早く返す事業になるか** | **なる。**賃貸の手取りを元金充当すれば10年前後の短縮・利息500〜840万削減（→3.3） |
| **1階を店舗テナントにするとどうか** | 賃料は上がるが融資・工事費・空室・税が同時に不利化。**店舗賃料が住居の約1.7倍を超えないと住居として貸すより不利**（→4章） |
| 最大の壁 | ①住宅ローンの「自宅1/2以上」要件 ②界壁・メーター分離などの工事費 ③**出口の狭さ**。テナントならさらに④用途地域 ⑤事業用ローンの条件 |
| 現在の売出物件で成立するか | 母集団1,279件中33件が形として成立。賃料が返済を上回るのは12件、**明確な余裕（余裕度1.2以上）は6件**。うち5件は外周区で、都心は新宿区四谷4（延床174㎡・商業地域・1.2億）の1件だけ（→ [hybrid.html](./hybrid.html)） |

> 本書は README の「D. 目的別の現実的な買い方」5（投資用）と1（自宅用）の**中間**にあたる型を扱う。
> 判定は最終的に README O章の5条件＋本書14章の追加2条件で行う。

## 1. 「事業として」を3つに分解する

「事業として買う」という一言には、実務上まったく別の3つの意思決定が混ざっている。
混ぜたまま銀行に行くと必ず話が噛み合わない。

| レイヤー | 選択肢 | 効いてくるもの |
|---|---|---|
| ① **融資の区分** | 住宅ローン / アパートローン（事業用） / 法人融資 | 金利・期間・審査・団信 ＝ **月々の返済額** |
| ② **税の区分** | 不動産所得（非事業的規模 / 事業的規模） / 法人所得 | 経費・減価償却・青色控除・損益通算 |
| ③ **実態** | 自宅がメインで一部を貸す / 収益物件に住む | 保険・出口・近隣関係・生活の質 |

**①だけが桁で効く。**②③は数万円単位、①は月10万円単位で変わる。
だから設計はいつも「どのローンを引けるか」から逆算する。

## 2. 3つの取り方の比較

同じ物件（総事業費5,500万円・自己資金600万円・借入4,900万円）を3通りで買った場合。

| | **A 賃貸併用（住宅ローン）** | **B 個人＋事業用ローン** | **C 法人取得** |
|---|---|---|---|
| 金利の目安 | 0.5〜1.5% | 2.5〜4.0% | 2.5〜4.5% |
| 期間 | 35年 | 20〜25年（構造の耐用年数に縛られる） | 15〜25年 |
| **月返済** | **13.2〜14.8万円** | **22.7〜29.2万円** | **27.7万円前後** |
| 自宅部分 | そのまま住める | 住める（自宅部分は融資対象外になることも） | **役員社宅**扱い。賃料相当額を法人に払う必要 |
| 団信 | あり（死亡＝無借金の収益物件が残る） | 原則なし／別途 | なし |
| 住宅ローン控除 | 居住用部分に対応する分だけ適用可 | 不可 | 不可 |
| 経費計上 | 賃貸部分の按分のみ | 賃貸部分の按分のみ | 広いが法人維持コスト（年20〜40万円）が乗る |
| 実行難易度 | 低〜中（取扱行を選ぶ） | 中（属性・自己資金2〜3割） | 高（実績なしの新設法人には出にくい） |

**1戸だけ貸したときの年間手取りは、賃料10万円/月でも約92万円**（空室・管理・修繕・保険を引いた77%換算）。
A と B の返済差は年間で約115〜175万円ある。
つまり **B・C を選んだ時点で、賃料は返済差を埋めきれない。**
「事業として買う」＝事業用ローンで買う、という意味なら、
23区で1戸賃貸の規模では**答えはノー**。棟数を増やすか、自宅であることを使うかの二択になる。

> 逆に言えば、A は「低金利・長期・団信」という住宅ローンの条件を、
> 収益を生む床にも適用できてしまう構造であり、そこが賃貸併用の唯一にして最大の旨味。

## 3. 都心で、自分のローンでは届かないとき

> 「都心に家が欲しい。でも自分だけのローンでは買えない。
>   だから1階を貸して取得し、ローンを早く返す事業にしたい」

この筋道は、**2つの別々の問いが1本につながっているように見えて、実は片方しか成立しない。**

| | 問い | 答え |
|---|---|---|
| **問1 取得力** | 1階の賃料は、借りられる額を増やすか | **ほぼノー**。増える枠は工事費でほぼ相殺される |
| **問2 返済加速** | 1階の賃料は、ローンを早く終わらせるか | **明確にイエス**。10年前後の短縮が現実に効く |

つまり **賃貸併用は「買えるようにする道具」ではなく「早く返す道具」**。
後半の狙いは正しく、前半の筋道が成立しない。計算は [loan_plan.html](./loan_plan.html)（`scripts/loan_plan.py`）で自分の数字に置き換えられる。

---

### 3.1 なぜ取得力が増えないか：借入可能額を決めるのは「審査金利」

住宅ローンで借りられる額は、**実行金利ではなく審査金利**で決まる。
変動0.7%で借りるつもりでも、銀行は返済比率を**3〜4%**で測る。ここが取得力の天井。

**年収別の借入可能額（返済比率30%・35年）**

| 年収 | 審査3.0% | 審査3.5% | 審査4.0% |
|---:|---:|---:|---:|
| 700万 | 4,547万 | 4,234万 | 3,952万 |
| 800万 | 5,197万 | **4,839万** | 4,517万 |
| 1,000万 | 6,496万 | 6,049万 | 5,646万 |
| 1,200万 | 7,795万 | 7,259万 | 6,775万 |

**賃料を年収に算入した場合の増分（年収800万・比率30%・審査3.5%）**

| 想定賃料 | 算入率70% | 算入率80% |
|---:|---:|---:|
| 8万/月 | +406万 | +465万 |
| 10万/月 | +508万 | +581万 |
| 12万/月 | +610万 | +697万 |
| 15万/月 | +762万 | +871万 |

**ここが決定的**：賃料12万/月を80%算入してもらって **+697万円**。
一方、賃貸化工事費は **550〜1,000万円**（→ 7.2）。
**増える借入枠より、賃貸化に要る金が大きいか、よくて同じ。**

しかも「賃料を年収に算入する」扱い自体が金融機関次第で、算入しない先も多い。
算入されなければ増分はゼロで、工事費だけが残る。

> **結論**：「自分のローンでは都心に届かないから1階を貸す」という筋道は、ここで切れる。
> 1階を貸しても、買える価格帯は上がらない。

### 3.2 では、都心で何が必要になるか

都心10区（千代田・中央・港・新宿・文京・渋谷・目黒・品川・台東・豊島）で
**戸建・所有権・再建築可・延床85㎡以上**の売出は94件、**最安が8,490万円**（2026-09-12時点）。
これに諸費用7%と賃貸化工事を足すと、総事業費はおよそ**9,600万〜1.1億**が入口。

総事業費1.08億（新宿区中落合3・9,580万＋諸費用670＋工事550）に必要な世帯年収：

| 自己資金 | 借入 | 比率30%・審査3.5% | 比率35%・審査3.5% | 比率35%・審査2.0% |
|---:|---:|---:|---:|---:|
| 1,000万 | 9,800万 | 1,620万 | 1,389万 | 1,113万 |
| 2,000万 | 8,800万 | 1,455万 | 1,247万 | 999万 |
| 3,000万 | 7,800万 | 1,289万 | 1,105万 | 886万 |
| 4,000万 | 6,800万 | 1,124万 | 964万 | 772万 |
| 5,000万 | 5,800万 | 959万 | 822万 | 659万 |

**動かせるレバーは4本しかない。効く順に：**

1. **自己資金**（頭金・親からの資金援助）
   ── 1,000万円積むごとに必要年収が約165万円下がる。最も確実に効く。
   直系尊属からの住宅取得等資金の贈与には非課税枠があるので、税理士に適用可否を確認する。
2. **ペアローン・収入合算**
   ── 世帯年収を上げる唯一の即効手段。年収800万＋400万で借入可能額は4,839万→7,259万。
   ただし**離職・離婚・片方の病気で一気に破綻する**。団信の付き方、持分割合、
   贈与税（負担割合と持分がずれると贈与認定）を設計しておくこと。
3. **審査金利の低い金融機関を探す**
   ── 表の右端の列。審査3.5%→2.0%で必要年収が2〜3割下がる。
   固定金利型は実行金利に近い値で審査する先もある。**複数行に当たる価値はここにある。**
4. **賃貸部分をアパートローンの別枠にする**
   ── 賃料手取りをDSCR1.25で割った返済原資から逆算して、
   賃料12万/月なら金利2.8%・25年で**約1,590万円**の別枠調達。
   住宅ローン枠を食わないので総額は増えるが、**総債務が増え、
   賃料が止まれば自宅家計が直撃される**。最後の手段。

**この4本を全部使って、ようやく都心の入口に届く。**
1階賃貸はこの4本のどれでもない。**取得の問題は、取得の手段で解くしかない。**

### 3.3 問2の答え：返済加速は本当に効く

取得できた後なら、話は逆転する。**賃貸の手取りを全額 元金に充当**した場合：

借入8,800万円・金利1.0%・35年、賃料12万/月（手取り9.2万）のとき

| 賃料手取りの使い方 | 月の上乗せ | 完済 | 短縮 | 総利息 | 削減 |
|---|---:|---:|---:|---:|---:|
| 使わない（返済のみ） | 0 | 35.0年 | — | 1,633万 | — |
| 50%を元金充当 | 4.6万 | 28.7年 | -6.3年 | 1,324万 | -309万 |
| **100%を元金充当** | **9.2万** | **24.2年** | **-10.8年** | 1,113万 | **-520万** |
| 150%を元金充当 | 13.9万 | 21.1年 | -13.9年 | 961万 | -672万 |

金利が上がるほど効果は大きくなる（借入8,000万・金利1.6%なら手取り9万充当で **11.3年短縮・利息840万削減**）。

**実行上の注意**
- 繰上返済は**「期間短縮型」**を選ぶ。返済額軽減型では利息削減が小さくなる
- **手取りを全額つぎ込む前に、修繕・空室・原状回復の備えを先に積む。**
  1戸しかない賃貸は空けば収入がゼロ。手元資金を削って繰上返済した直後に
  空室と給湯器故障が重なるのが、この型の典型的な事故
- 住宅ローン控除の期間中は、繰上返済で残高を減らすと控除額も減る。
  **控除期間が終わってから本格的に繰り上げる**ほうが有利なことが多い（税理士に試算してもらう）
- 変動金利なら、繰上返済用の資金は**金利上昇時の緩衝材**でもある。全部を元金に入れない選択肢も持っておく

### 3.4 都心固有の論点：1階を「店舗」として貸せるか

都心の路面なら、1階を住居ではなく**店舗テナント**として貸すと賃料単価が上がる。
ただし融資・工事費・空室・税・法規がまとめて切り替わり、
**店舗賃料が住居の約1.7倍を超えないと、住居として貸すより不利になる**。

→ 詳細は **4章「1階を『テナント（店舗）』にする場合」** で扱う。
用途地域の可否表、損益分岐倍率、事業用ローンの感度、消費税の扱い、進め方の順番はそちら。

---

### 3.5 このケースの現実的な進め方

1. **事前審査を3行以上で取る**（1階賃貸の話は最初からする）。
   「賃貸併用に住宅ローンを出すか」「自宅部分の割合の要件は」「賃料を年収に算入するか」「審査金利は」
   ── この4問の答えが行ごとに違う。**取得力の実額はここでしか確定しない**
2. その回答で**自分の到達可能額を確定**させる（[loan_plan.html](./loan_plan.html) の数字を実額に置き換える）
3. 到達可能額と、都心の入口（総事業費9,600万〜1.1億）を突き合わせる
4. **届かなければ、賃貸併用ではなく取得手段で埋める**（頭金・ペアローン・審査金利の低い行）
5. それでも届かなければ、**エリアを一段落とす**。
   同じ賃貸併用でも、外周区なら余裕度1.4〜1.9で成立し実質住居費が月4〜6万円になる（→ 8章）。
   **「都心の家」と「1階賃貸で早く返す」は、両立しないなら後者を優先したほうが家計は強くなる**
6. 取得できたら、**賃料手取りは繰上返済（期間短縮型）に回す**。ただし備えを積んでから

## 4. 1階を「テナント（店舗）」にする場合

1階を住居ではなく**店舗テナント**として第三者に貸す前提に変えると、
賃料だけでなく**融資・工事費・空室・税・法規のすべてが同時に切り替わる**。
上がるのは賃料だけで、他は全部不利側に動く。だから結論はひとつの数字に集約できる。

> **店舗賃料が住居賃料の約1.7倍を超えないと、テナント化は住居として貸すより不利になる。**

現在の売出データで計算すると、賃貸併用として成立する33件のうち
**テナント化で採算が改善したのは商業地域の3件だけ**、残り30件は悪化した。

---

### 4.1 なぜ悪化するのか：4つが同時に動く

| 項目 | 住居として貸す | 店舗テナントとして貸す | 効き方 |
|---|---|---|---|
| **店舗部分の融資** | 住宅ローン 1.0% / 35年 | **事業用ローン 2.8% / 25年** | ここが最大。月返済が跳ねる |
| 工事費（中古戸建） | 550万円 | **750万円**（異種用途区画・独立出入口・引込増強・ファサード） | +200万円 |
| 空室・滞納 | 10% | **18%**（テナントは決まるまで長い） | 手取り率 77% → 69% |
| 固都税等 | 総額の年0.35% | 年0.45%（住宅用地特例の枠は住宅戸数で決まり、店舗は数えない） | 保有コスト増 |
| **賃料** | ×1.0 | **×1.05〜2.0（用途地域次第）** | ここだけがプラス |

**賃料の倍率をいくつにすると逆転するか**（用途地域の制限を外して倍率だけを動かした34件で試算）

| 店舗賃料の倍率 | テナントが住居を上回る件数 | テナント側の余裕度 中央値 |
|---:|---:|---:|
| ×1.2 | 0 / 34 | 0.68 |
| ×1.4 | 0 / 34 | 0.79 |
| ×1.6 | 4 / 34 | 0.91 |
| **×1.8** | **31 / 34** | 1.02 |
| ×2.0 | 32 / 34 | 1.13 |
| ×2.2 | 33 / 34 | 1.25 |

（住居として貸した場合の余裕度 中央値は 0.90）

**事業用ローンの条件で結論がひっくり返る**（倍率×1.7＝近隣商業 相当で固定）

| 事業用ローン | 上回る件数 | 余裕度 中央値 |
|---|---:|---:|
| 1.0% / 35年 | 33 / 34 | 1.50 |
| 2.0% / 30年 | 33 / 34 | 1.19 |
| 2.8% / 25年 | 16 / 34 | 0.96 |
| 3.5% / 20年 | **0 / 34** | 0.78 |

**読み取り**：賃料がいくらになるかを議論する前に、**用途地域**と**事業用ローンの条件**の2つで
勝負がついている。この2つを先に潰さないと、他の検討は全部無駄になる。

### 4.2 最初の関門：用途地域

**他人に貸す独立したテナント区画**として1階を店舗にできるか。建築基準法 別表第2の考え方の整理。

| 用途地域 | 店舗テナント | 賃料倍率の目安 | 注記 |
|---|:--:|---:|---|
| 商業地域 | ◎ | ×2.0 | |
| 近隣商業地域 | ◎ | ×1.7 | |
| 準工業地域 | ◎ | ×1.3 | |
| 準住居地域 | ○ | ×1.4 | |
| 第一種住居地域 | ○ | ×1.4 | 床面積3,000㎡以内。業種制限 |
| 第二種住居地域 | ○ | ×1.4 | 床面積10,000㎡以内。業種制限 |
| 第二種中高層住居専用 | △ | ×1.15 | 2階以下・1,500㎡以内かつ業種限定 |
| 第一種中高層住居専用 | △ | ×1.10 | 2階以下・500㎡以内かつ業種限定 |
| 第二種低層住居専用 | △ | ×1.05 | 2階以下・150㎡以内かつ日用品店等に限定 |
| **第一種低層住居専用** | **✕** | — | 兼用住宅（自宅と一体・店舗50㎡以下）の枠しかなく、**独立したテナント区画として他人に貸すのは原則不可** |
| 工業地域 | ○ | ×1.1 | 住宅は建てられるが住環境・出口が弱い |
| 工業専用地域 | ✕ | — | 住宅そのものが建てられない |
| 田園住居地域 | ✕ | — | 農産物直売所等に限られる |

> 規模・業種の細目（物販／飲食／サービスで扱いが違う）と最終判断は**特定行政庁**。
> 上の表は当たりを付けるためのもので、根拠にはならない。

⚠ **このリポジトリのデータでは、戸建・土地392件のうち用途地域が判明しているのは66件だけ。**
[hybrid.html](./hybrid.html) の候補に残っていること自体は「店舗可」の証明にならない。
**役所（建築指導課）での確定が初手**であり、ここが✕なら他の検討は全部意味を失う。

---

### 4.3 融資：自宅にまで影響する

- 住宅ローンの対象は「住宅」部分。**店舗部分は原則対象外。**
- フラット35は店舗等併用住宅を扱うが、住宅部分が全体の1/2以上であることが前提で、
  融資対象も住宅部分の建設費・購入価額まで。
- 民間は「自宅分＝住宅ローン ＋ 店舗分＝事業用ローン」のミックスか、全体を事業用ローン。
- **自宅部分が延床の1/2を割ると、自宅部分にすら住宅ローンが使えなくなる。**
  店舗を大きく取りたい誘惑がそのまま融資条件の悪化に直結する。
- つまり 3.2 で挙げたレバー4本のうち「④賃貸部分を事業用ローンの別枠にする」は、
  テナント前提では**選択肢ではなく必須**になる。

**金融機関に最初に聞く4問（店舗版）**

1. 1階を第三者に**店舗として**貸す前提で、自宅部分に住宅ローンを出すか
2. 店舗部分は事業用ローンか。**金利・期間・求める自己資金割合**は
3. 店舗の賃料を返済原資として評価するか。求めるDSCRの水準は
4. 審査金利は何%か

> 2番の答えが「3.5%・20年」なら、上の感度表のとおりこの型は成立しない。
> **物件を探す前にこの回答を取る。**

---

### 4.4 建築・法規：住居賃貸との違い

- 店舗は**特殊建築物**。既存戸建を店舗に変える場合、**用途変更の確認申請は200㎡超**で必要
  （小規模テナントなら不要なことが多いが、面積の数え方を建築士に確認する）
- **異種用途区画**：住宅と店舗が同一建物内にあると、準耐火構造の床・壁＋特定防火設備で
  区画する必要が出る。これが工事費に直接効く（住居賃貸の界壁より重い）
- **避難経路を分ける**：店舗の出入口・避難動線と自宅のそれを交差させない
- **飲食にするなら**：保健所の営業許可、給排気ダクトの経路（**上階が自宅＝臭気が直撃する**）、
  グリストラップ、火気使用設備に応じた消防設備、深夜営業の届出
- **電気容量・給排水の口径**：住居想定では足りない。厨房・空調・什器で一気に増える
- ファサード・シャッター・看板の位置、ゴミ置場、搬入動線、駐輪

---

### 4.5 契約と運営

- **事業用定期借家**にするか普通借家か。将来の建替え・自宅化・売却の自由度を残すなら定借
- **保証金**：賃料の6〜12ヶ月が相場（住居の敷金1〜2ヶ月と桁が違う）。償却（敷引き）の設定
- **造作買取請求権の排除特約**と、原状回復＝スケルトン返しの明記
- 中途解約条項（予告期間・違約金）、用途・業種の限定と変更承諾
- 営業時間・騒音・臭気・看板の取り決め。**自宅の下で他人が営業する**ことの生活影響
- 連帯保証人／保証会社
- **1区画しかない＝空けば収入ゼロ。**テナントは住居より決まるまで長い（数ヶ月〜1年）

---

### 4.6 税：住居賃貸と決定的に違う点

| 項目 | 住居として貸す | 店舗として貸す |
|---|---|---|
| 消費税 | 住宅の貸付けは**非課税** | **課税取引** |
| 建物の仕入税額控除 | 不可（居住用賃貸建物の制限） | **店舗部分は控除の余地あり** |
| インボイス | ほぼ無関係 | テナントが課税事業者なら適格請求書を求められる |
| 固定資産税 住宅用地特例 | 住宅の戸数で200㎡枠が増える | 店舗は戸数に数えない＝枠が増えない |
| 所得区分 | 不動産所得 | 不動産所得（事業的規模の判定は同じ5棟10室） |

消費税は両刃。課税事業者を選べば**店舗部分の工事費に係る消費税を控除できる余地**があるが、
課税事業者選択の2年（調整対象固定資産を取得した場合は3年）縛り、インボイス登録、
簡易課税との比較がセットで付いてくる。

> **順番を間違えると選べなくなる。取得と工事の前に税理士に相談すること。**

---

### 4.7 出口

- **実需の買い手はさらに減る**（自宅の下に他人の店がある家を買う人は限られる）
- 一方で**収益還元では有利に働きうる**：1階店舗の賃料が高いぶん、投資家の評価は上がる
- 「テナント入居中で売る」のか「空にして売る」のかで評価も買い手も変わる。
  定期借家にしておくと、更地化・自宅化・建替えの出口を自分で選べる
- 結局の本体は土地値。[listings.html](./listings.html) の値持ち評価に戻る

---

### 4.8 テナント側の効き目：事業用ローンは速く消せる

不利ばかりではない。**店舗の賃料は高いので、その手取りを事業用ローンの元金に全額充当すると、
25年のローンが8〜11年で終わる**（候補上位での試算）。

| 例 | 事業用ローン | 通常完済 | 手取り全額充当 | 短縮 | 利息削減 |
|---|---:|---:|---:|---:|---:|
| 葛飾区立石1（商業） | 1,366万 | 25年 | **7.6年** | -17.4年 | -384万 |
| 江戸川区鹿骨4 | 817万 | 25年 | **8.0年** | -17.0年 | -224万 |
| 葛飾区西水元6 | 1,461万 | 25年 | **9.1年** | -15.9年 | -378万 |

金利の高い事業用ローンから潰すのが定石。**自宅の住宅ローンはそのまま35年走る**ので、
「家全体が早く終わる」わけではない点に注意。消えるのは店舗部分の借金。

---

### 4.9 進め方（順番を間違えない）

1. **用途地域を役所で確定**（建築指導課）。想定業種が入るか、規模制限は。**ここが✕なら終わり**
2. 地場の**店舗系仲介**に、その立地・面積で**坪いくらで・何ヶ月で決まるか**を聞く。成約事例を出してもらう
3. その坪単価を**同エリアの住居の坪単価と比べる**。**1.7倍が損益分岐**
4. 金融機関3行に 4.3 の4問。**事業用ローンが2.8%/25年より悪いなら成立しない**
5. 建築士に異種用途区画・確認申請の要否・工事費の概算
6. 税理士に消費税の順番（課税事業者選択・インボイス・簡易課税）
7. **ここまで全部通ってから**物件を絞る

---

### 4.10 撤退条件（テナント版・13章への追加）

- 用途地域で店舗テナントが建てられない／規模・業種制限で想定業種が入らない
- 店舗の**実勢賃料が住居の1.7倍に届かない**
- 事業用ローンが**3.5%/20年より悪い条件**しか出ない
- 地場の店舗仲介が「この立地では決まらない」と言う／成約事例を出せない
- 自宅部分が延床の1/2を割る設計にしないと店舗面積が確保できない
- 飲食を想定しているのに、上階が自宅で**給排気ダクトのルートが取れない**
- 「賃料が高いから」だけで店舗を選んでいる（融資・空室・税の不利を計算していない）

## 5. 器の設計：「自宅1/2以上」がすべてを決める

住宅ローン（フラット35を含む多くの金融機関）は、併用住宅について
**「住宅部分＝自ら居住する部分の床面積が、建物全体の1/2以上」**を要件とする。
※金融機関により「賃貸部分は融資対象外」「賃貸部分はアパートローンと組み合わせ」など扱いが分かれる。**必ず個別に確認する。**

ここから設計上の制約が自動的に決まる。

| 建物 | 1階を丸ごと貸すと | 判定 |
|---|---|---|
| 2階建て・各階同面積 | 賃貸50% / 自宅50% | **危険**。図面の実測でわずかに割れると要件を落とす |
| 2階建て・1階の一部（玄関・水回り・納戸）を自宅側に残す | 賃貸35〜45% | ○ 現実的 |
| 3階建て | 賃貸30〜35% | ◎ 最も素直 |

**設計ルール**
1. 賃貸部分は**延床の45%まで**に抑える（本リポジトリのスクリーナーもこの閾値を使用）。
2. 面積は「なんとなく半分」ではなく**確認申請図面と登記床面積で確定**させる。按分計算の根拠は税務でも使う。
3. **区分登記はしない。** 分けると住宅ローン・住宅ローン控除・住宅用地特例・売却の全部が面倒になる。
4. 賃貸戸は 20〜45㎡（1R〜1LDK）。これ以上大きくすると自宅が痩せ、出口も狭くなる。

> ⚠ **住宅ローンで買って自宅に住まず全部貸すのは契約違反。** 期限の利益喪失＝一括返済請求の対象。
> 「とりあえず住宅ローンで買って後で全部貸す」は選択肢に入れない。

---

## 6. 建築・法規：1階を貸すと建物の「種類」が変わる

内部で行き来できない独立住戸を作った時点で、その建物は一戸建て住宅ではなくなる。

| 形 | 建築基準法上の扱い | 規制の重さ |
|---|---|---|
| 内部で行き来できる（自分の家の一室を貸す・下宿） | 一戸建て住宅 | 軽い（ただし他人に貸す実務が難しい） |
| 各戸が**直接地上へ出られる**・共用廊下なし | **長屋** | 中。特殊建築物ではない＝**用途変更の確認申請が不要** |
| 共用廊下・共用階段がある | **共同住宅**（特殊建築物） | 重い。200㎡超で用途変更の確認申請、耐火・避難・消防の要件が上がる |

**実務上の要点**

- 1階に専用玄関を独立して設け、**長屋**として計画すると規制が一段軽くなる。設計の初手はここ。
- **界壁**：長屋・共同住宅の各戸の界壁は、遮音性能を持ち、かつ準耐火構造として小屋裏・天井裏まで達させる必要がある（法30条・令114条）。
  上下階の界床の遮音は、法規以前に**クレームと退去の最大要因**。既存戸建の改修では遮音が最も金と手間を食う。
- **用途地域**：第一種低層住居専用地域でも、住宅・長屋・共同住宅は建てられる。
  一方で**1階を店舗として貸すのは原則不可**（兼用住宅として床面積50㎡以下かつ建物の1/2未満などの要件内に限られる）。
  「1階を貸す」でも住居貸しと店舗貸しで難易度がまったく違う。
- **設備の分離**：電気・ガス・水道の**メーターを分ける**。分けないと使用量を按分請求することになり、実務が破綻する。
  水道の口径増径や引込追加が必要な場合があり、**私道の掘削承諾が取れないとここで詰む**（→ risk_guide.md 1章）。
- **消防**：用途判定（長屋か共同住宅か）で必要設備が変わる。所轄消防署で事前相談。
- **駐輪・ゴミ置場・郵便受け・表札**：賃借人の生活動線が自宅と交差しない配置にする。ここを詰めないと生活の質が落ちる。

**1階特有の論点**
浸水（内水氾濫を含む）／防犯／日照・採光／隣地からの視線／庭・専用部の管理責任。
**1階住戸は上階より賃料が下がる**（本リポジトリの試算では −7% を置いている）。

## 7. お金の構造

### 7.1 式

```
総事業費 = 物件価格 + 諸費用(価格の約7%) + 賃貸化工事費
月返済   = 元利均等（総事業費 − 自己資金、金利、期間）
手取り率 = 1 − 空室10% − 管理5% − 修繕/原状回復6% − 保険雑費2% = 77%
賃貸の手取り = 賃料 × 77% − 固都税等 × 賃貸部分の床面積比

損益分岐賃料 = (月返済 + 固都税等) × 賃貸部分の床面積比 ÷ 77%
実質の住居費 = 月返済 + 固都税等 − 賃貸の手取り
```

**見るべき数字は2つだけ。**

1. **余裕度 ＝ 想定賃料 ÷ 損益分岐賃料**。1.0を割ったら、賃貸部分は返済を賄えず自宅側の持ち出し。
2. **実質の住居費**。これを**いま払っている家賃と比べる**。それ以外の使い方をしない。

利回りで見てはいけない。自宅部分が収益を生まない以上、物件全体の利回りは定義上ずっと低く出るし、
「表面利回り◯%」は賃貸併用では意味を持たない指標になる。

### 7.2 賃貸化工事費の目安（中古戸建を改修する場合／木造・都内）

| 項目 | 目安 |
|---|---|
| 玄関の分離・外部階段 | 80〜200万円 |
| 水回り一式新設（キッチン・浴室・洗面・便所） | 200〜350万円 |
| 界壁・界床の遮音／準耐火 | 80〜200万円 |
| 電気・ガス・水道のメーター分離、引込・増径 | 50〜150万円 |
| 内装・建具・設備 | 100〜200万円 |
| 設計・確認申請（必要な場合） | 30〜100万円 |
| **合計** | **概ね550〜1,000万円** |

スクリーナーの既定値は**550万円**（下限寄り）。**見積りを取ったら必ず置き換えて再計算する。**
ここが200万円ずれると余裕度は簡単に1.0を割る。

### 7.3 感度（何で壊れるか）

| 変数 | 動かすと | 効き方 |
|---|---|---|
| 金利 +1.0% | 月返済 +約2.5万円（借入4,900万・35年） | **最も効く。** 変動で組むなら金利上昇分を自己資金で吸収できるか |
| 賃料 −10% | 手取り −約0.8万円/月 | 効くが致命的ではない |
| 空室4ヶ月 | 年間 −約40万円 | **1戸しかない＝空けば収入ゼロ。** 分散が効かないのが単室賃貸の本質的弱点 |
| 工事費 +200万円 | 月返済 +約0.6万円 | 見積り前の試算は常に楽観に振れる |
| 大規模修繕（15年目） | 100〜300万円 | 積立していないと必ず自宅家計から出る |

   外周区の4〜7万円とは別世界にある。**「回る」＝「安く住める」ではない。**
   1.2億の総事業費に必要な世帯年収は3章の表を見ること。この物件は「売り急ぎ」タグ付きで、
   価格が相場より落ちていることが余裕度を押し上げている可能性が高い（＝再現性は低い）。
2. **城南・城西（世田谷・目黒・渋谷・新宿・杉並）では、1階賃貸は住居費の一部補填にしかならない。**
   それでも賃貸の手取りは月6.5〜11.5万円あり、その分だけ実質住居費が下がる（年80〜140万円）。
   「回らないからやらない」ではなく、**何のためにやるのかを言い換える**必要があるということ。
3. **土地から新築する型は、建築費が総額の過半を占めて一気に不利になる。**
   容積が余っていても「建てられる＝建てるべき」ではない。
   スクリーナーは想定延床を150㎡（自宅105＋賃貸45）で頭打ちにしている。
4. **再建築不可・借地権はここで完全に脱落する（100件）。**
   README の「安く買えるルート」の主力が、賃貸併用では使えない。
   融資が付かない物件は、賃貸併用という型と根本的に相性が悪い。

> ⚠ **想定賃料は推定値**であり、賃料の一次データではない。
> 区の実取引㎡単価から利回りを逆算した近似（`scripts/screen_hybrid.py` の `rent_per_m2`）。
> 単身向け小型住戸は㎡単価が上振れするため推定は保守側（低め）に出る。
> **判断の前に、SUUMO賃貸で同一エリア・同面積の実募集を3件以上見て置き換える。**

## 9. 税：何が経費になり、何がならないか

| 項目 | 扱い |
|---|---|
| 所得区分 | **不動産所得**。1戸なら「事業的規模（5棟10室）」ではない |
| 青色申告特別控除 | 非事業的規模では**最大10万円**（65万円は事業的規模＋複式簿記＋e-Tax等が要件） |
| 専従者給与 | 非事業的規模では**不可** |
| 経費 | 賃貸部分に**床面積按分**した分のみ。固都税・保険・修繕・管理費・借入金利息（元本は経費でない） |
| 減価償却 | **建物の賃貸部分のみ**（土地は不可）。木造住宅の法定耐用年数22年。中古は簡便法で短くなる |
| 損益通算 | 不動産所得の赤字は給与所得等と通算可。ただし**土地等の取得に係る負債利子は通算対象外** |
| 住宅ローン控除 | 家屋の**床面積の1/2以上が自己の居住用**であることが要件。控除対象は**居住用部分に対応する借入金**（按分） |
| 固定資産税 | 併用住宅は居住部分の割合で住宅用地の適用率が決まる。居住部分1/2以上なら敷地全体が住宅用地。**住宅1戸につき200㎡まで課税標準1/6**＝賃貸戸が増えると枠も増える |
| 消費税 | **住宅の貸付けは非課税**。したがって建物の消費税還付は狙えない（2020年改正で居住用賃貸建物の仕入税額控除は不可）。**店舗貸しは課税** |
| 不動産取得税・登録免許税 | 住宅の軽減は主に自己居住部分。賃貸部分の扱いは要確認 |
| 火災保険 | 賃貸部分があると「住宅物件」でなく併用扱いとなり保険料が上がる場合がある。施設賠償責任も検討 |

**実務上の一番のポイント**：按分の根拠（床面積）を**取得時に図面と登記で確定**させ、以後ずっと同じ比率で通すこと。
後から比率を動かすと税務署への説明がつかなくなる。取得の前に税理士に按分方針を確認しておく。

## 10. 出口：ここが賃貸併用の最大の弱点

**賃貸併用住宅は、売るときに買い手が2種類ともいなくなる構造を持つ。**

| 買い手 | なぜ買わないか |
|---|---|
| 実需（自分で住みたい人） | 賃貸部分が邪魔。他人が同じ建物にいるのを嫌う。価格に賃貸部分の建築費が乗っているのに使えない |
| 投資家（利回りで買う人） | 自宅部分が空床でしかない。全体を収益還元で見ると利回りが低すぎる |

結果、**査定が「取引事例（実需）」と「収益還元（投資）」のどちらでも低く出る**。
これは価格が下がる、ではなく**流動性が落ちる**（買い手が現れるまでの時間が延びる）という形で効く。

**対策（取得前に決めておくこと）**

1. **定期借家契約にする**（借地借家法38条）。普通借家だと正当事由なしに退去させられず、
   「自宅に戻す」「更地で売る」という出口が借家人の意思に縛られる。定借なら期間満了で確定終了できる。
   ※定借は普通借家より賃料が5〜10%程度下がる傾向。**流動性のために賃料を払う**という取引と理解する。
2. **単世帯に戻せる設計にしておく。** 界壁を撤去可能に、2階から1階へ内部階段を後付けできる位置に。
   「賃貸をやめて広い一戸建てとして売る」という第2の出口を物理的に残す。
3. **区分登記しない。** 一体で売れなくなる。
4. **賃貸部分を大きくしすぎない。** 45%を超えると住宅ローン要件も出口も同時に悪化する。
5. **土地の価値で出口を担保する。** 建物を評価してもらえない前提に立つと、
   結局は「土地として売れるか」＝ README/listings.html の値持ち評価に戻る。**そこが本体。**

## 11. リスク（risk_guide.md 追補）

賃貸併用に固有で、既存のリスクガイドに載っていないもの。

| リスク | 内容 | 確認先 |
|---|---|---|
| **単室集中リスク** | 1戸しかない＝空室率は0%か100%。分散が効かない。退去〜次の入居まで2〜4ヶ月は普通に空く | 地場の賃貸仲介（実際の成約期間） |
| **同居ストレス** | 音・臭い・来客・ゴミ・共用部の使い方。オーナーが同じ建物にいるため直接クレームが来る | 実際にやっている人の話 |
| **管理者としての責任** | 設備故障は深夜でも自分に来る。管理委託（賃料5%）で切り離せるかを最初に決める | 管理会社 |
| **入居者を選べないリスク** | 差別的な選別はできない。滞納・近隣トラブル時の対応を事前に決めておく | 保証会社・管理会社 |
| **1階の浸水** | 内水氾濫を含む。1階住戸は直撃。保険料・空室・退去に効く | ハザードマップ／listings.json の `hazard`・`elev` |
| **住宅ローンの用途違反** | 自宅に住まなくなった時点で契約違反。転勤等でも要届出 | 金融機関 |
| **金利上昇** | 変動で組んだ場合、返済増を賃料で吸収できない（賃料は金利に連動しない） | 自分の返済比率 |
| **賃貸部分の陳腐化** | 15年で設備は一巡。修繕を積み立てていないと自宅家計を直撃 | 見積り |
| **既存不適格** | 現況延床が容積上の建築可能床を超えている中古戸建は、増改築・用途変更で床を減らされる可能性。融資審査にも響く | 建築士・行政 |

## 12. 専門家に聞くこと（README K章の追補）

**不動産業者（地場の賃貸仲介にも）**
- この面積・この間取りの1階住戸は、いくらで、何ヶ月で埋まるか。**直近の成約事例**を見せてほしい
- 1階であることの減価はいくらか。専用庭・専用玄関は加点になるか
- 賃貸併用住宅の売却事例はあるか。何ヶ月かかったか

**建築士**
- 1階に独立住戸を切り出せるか。**長屋として計画できるか**（共同住宅にせずに済むか）
- 界壁・界床の遮音と準耐火をどう納めるか。概算は
- 用途変更の確認申請は要るか
- 自宅部分と賃貸部分の床面積比を図面上いくつにできるか
- 単世帯に戻せる設計にした場合の追加費用は

**金融機関（3行以上・最初に聞く4問）**
1. 賃貸併用住宅に住宅ローンを出すか。**自宅部分の割合の要件は何%か**
2. 賃貸部分も融資対象に含まれるか、アパートローンとの組み合わせになるか
3. **賃料収入を返済比率の計算に算入するか。算入率は何%か**
4. **審査金利は何%か**（＝借入可能額の天井。行ごとに1.5%以上違うことがある）

追加で：団信は全額に付くか／完済時年齢の上限／ペアローンの場合の団信と持分／
1階を店舗として貸す場合の扱い。**取得力の実額は事前審査でしか確定しない。**

**税理士**
- 床面積按分の方針。減価償却の取り方
- 住宅ローン控除と不動産所得の申告をどう並立させるか
- 法人化する意味があるか（この規模では通常ない、の確認）

**行政**
- 建築指導課：用途地域、長屋/共同住宅の判定、既存不適格の有無
- 消防署：用途判定と必要設備
- 水道局：口径増径・引込追加の可否と費用

## 13. 撤退条件

以下のいずれかに当たったら、賃貸併用としての検討を止める（学習用としては記録して残す）。

- 自宅部分を**延床の1/2以上**にできない／面積比を図面で確定できない
- 取扱い金融機関で**住宅ローンが出ない**（＝事業用ローンしか選べない → 2章のとおり成立しない）
- 賃貸化工事の**見積りを入れると余裕度が1.0を割る**
- 地場の賃貸仲介が「この面積・この立地では埋まらない」と言う／成約事例を出せない
- 1階が浸水想定区域内で、賃借人に説明できるリスク水準を超える
- **私道の掘削承諾が取れず**、メーター分離・水道増径ができない
- 単世帯に戻す設計上の余地がなく、出口が「賃貸併用として売る」1本しかない
- 再建築不可・借地権（そもそも入口で脱落）
- **「家賃収入で儲かる」と思って検討している**（＝住居費削減という本来の目的を見失っている）
- **取得力が足りないのを、賃貸部分を大きくすることで埋めようとしている**
  （賃貸45%超は自宅50%ルールと出口を同時に壊す。取得の問題は取得の手段で解く → 3.2）
- 事前審査を1行しか取らずに「借りられない」と結論している（審査金利は行ごとに1.5%以上違う）
- **1階をテナントにする前提なのに、用途地域と事業用ローンの条件を確認していない**（→ 4.10 に専用の撤退条件）

## 14. 判定ルール（README O章の賃貸併用版）

README O章の5条件に、賃貸併用では次の2つを**追加**して、計7条件すべてを満たさない限り「買い」としない。

6. **自宅1/2以上を図面で確定でき、住宅ローンを出す金融機関を1行以上、実名で特定できている**
   （希望ではなく**事前審査の回答**で。3行以上当たったうえで）
7. **賃貸をやめても成立する**（賃料ゼロでも返済を続けられる／単世帯に戻して売れる）

条件7が本質。**賃料をあてにしないと払えない返済額は、そもそも組んではいけない。**
1階の賃料は「あると住居費が下がるもの」であって、「ないと破綻するもの」にしてはならない。
そう設計できたときだけ、この型は強い。

## 付録：スクリーナーの使い方

```bash
# 既定パラメータ（金利1.0%・35年・自己資金600万円・賃貸化工事550万円）
python3 scripts/screen_hybrid.py

# 自分の条件に置き換えて再計算
python3 scripts/screen_hybrid.py --rate 1.6 --years 35 --equity 1200 --reno-man 800 --top 40

# 事業用ローンで組んだ場合を見る
python3 scripts/screen_hybrid.py --rate 2.8 --years 25
#   → 同じ33件で、余裕度1.0以上は 12件 → 2件、中央値は 0.92 → 0.58 に落ちる。
#     これが「事業として買う」と成立しないことの実測。
```

**自分は住まず全部貸す前提で計算する**（住宅ローンが使えない代わりに全床が収益）：

```bash
python3 scripts/screen_hybrid.py --use rentout --own-rent 15
```

→ 判断の分かれ目は [land_strategy.md](./land_strategy.md) 4bis、制度は [subsidies.md](./subsidies.md)。

**1階を店舗テナントにする前提で計算する**（用途地域・事業用ローン・空室・固都税・工事費がまとめて切り替わる）：

```bash
python3 scripts/screen_hybrid.py --use tenant

# 事業用ローンの条件を差し替えて、どこで結論が反転するかを見る
python3 scripts/screen_hybrid.py --use tenant --biz-rate 2.0 --biz-years 30
python3 scripts/screen_hybrid.py --use tenant --biz-rate 3.5 --biz-years 20
```

都心に絞り、自分の年収で届くかを見る：

```bash
# 都心10区のみ・世帯年収1,200万・賃料を年収に80%算入・自己資金2,000万
python3 scripts/screen_hybrid.py --core-only 1 --income 1200 --rent-count 0.8 \
        --equity 2000 --max-price 20000
```

各候補に「借入可能額」「必要な自己資金」「賃料手取りを元金充当した場合の完済年数・利息削減」が付く。

取得力と返済加速だけを見る（物件を特定しない段階）：

```bash
python3 scripts/loan_plan.py --income 800 --partner 400 --equity 2000 --target 10800 --rent 12
```

4ルートの取得力比較・必要頭金の逆算・繰上返済シミュレーションを
`loan_plan.html` と `data/loan_plan.json` に出力する。

出力：`hybrid.html` / `loan_plan.html` と、対応する JSON。
前提値はすべて `scripts/screen_hybrid.py` の `PARAMS` と `scripts/loan_plan.py` の引数既定値に集約してある。

**このスクリーナーの正しい使い方**は、上位の物件を買うことではない。
**パラメータを動かして、判断がどこで反転するかを見ること。**
金利を1%上げる、工事費を800万円にする、賃料を10%下げる——
それで消える候補は、最初から余裕がなかったということ。
