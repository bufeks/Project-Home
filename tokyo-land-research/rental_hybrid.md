# 一階を貸す前提で「事業として」家を買えるか（rental_hybrid.md）

問い：**一階を賃貸に回すことを前提に、事業として家を買えないか。**

結論から書く。**買える。ただし「事業として」買うと成立しない。**
成立するのは「住宅ローンで自宅として買い、その一部を貸す」＝**賃貸併用住宅**の形だけである。
この一行の意味を分解するのが本書。

---

## 0. 先に結論だけ

| 問い | 答え |
|---|---|
| 1階を貸す家を買えるか | 買える。賃貸併用住宅として一般的な形 |
| 事業用ローン／法人で買えるか | 買えるが、23区の価格で**1戸だけ貸す規模では返済が埋まらない**（下記2章） |
| 儲かるか | 儲からない。**住居費が下がる**だけ。そこを取り違えると全部の判断を間違える |
| 税務上「事業」か | 1戸なら不動産所得だが**事業的規模（5棟10室）ではない**。青色申告特別控除は最大10万円 |
| 最大の壁 | ①住宅ローンの「自宅1/2以上」要件 ②界壁・メーター分離などの工事費 ③**出口の狭さ** |
| 現在の売出物件で成立するか | 母集団1,273件中31件が形として成立。賃料が返済を上回るのは12件、**明確な余裕（余裕度1.2以上）があるのは外周区の4件だけ**（→ [hybrid.html](./hybrid.html)） |

> 本書は README の「D. 目的別の現実的な買い方」5（投資用）と1（自宅用）の**中間**にあたる型を扱う。
> 判定は最終的に README O章の5条件＋本書12章の追加2条件で行う。

## 1. 「事業として」を3つに分解する

「事業として買う」という一言には、実務上まったく別の3つの意思決定が混ざっている。
混ぜたまま銀行に行くと必ず話が噛み合わない。

| レイヤー | 選択肢 | 効いてくるもの |
|---|---|---|
| ① **融資の区分** | 住宅ローン / アパートローン（事業用） / 法人融資 | 金利・期間・審査・団信 ＝ **月々の返済額** |
| ② **税の区分** | 不動産所得（非事業的規模 / 事業的規模） / 法人所得 | 経費・減価償却・青色控除・損益通算 |
| ③ **実態** | 自宅がメインで一部を貸す / 収益物件に住む | 保険・出口・近隣関係・生活の質 |

**①だけが桁で効く。**②③は数万円単位、①は月10万円単位で変わる。
だから設計はいつも「どのローンを引けるか」から逆算する。

## 2. 3つの取り方の比較

同じ物件（総事業費5,500万円・自己資金600万円・借入4,900万円）を3通りで買った場合。

| | **A 賃貸併用（住宅ローン）** | **B 個人＋事業用ローン** | **C 法人取得** |
|---|---|---|---|
| 金利の目安 | 0.5〜1.5% | 2.5〜4.0% | 2.5〜4.5% |
| 期間 | 35年 | 20〜25年（構造の耐用年数に縛られる） | 15〜25年 |
| **月返済** | **13.2〜14.8万円** | **22.7〜29.2万円** | **27.7万円前後** |
| 自宅部分 | そのまま住める | 住める（自宅部分は融資対象外になることも） | **役員社宅**扱い。賃料相当額を法人に払う必要 |
| 団信 | あり（死亡＝無借金の収益物件が残る） | 原則なし／別途 | なし |
| 住宅ローン控除 | 居住用部分に対応する分だけ適用可 | 不可 | 不可 |
| 経費計上 | 賃貸部分の按分のみ | 賃貸部分の按分のみ | 広いが法人維持コスト（年20〜40万円）が乗る |
| 実行難易度 | 低〜中（取扱行を選ぶ） | 中（属性・自己資金2〜3割） | 高（実績なしの新設法人には出にくい） |

**1戸だけ貸したときの年間手取りは、賃料10万円/月でも約92万円**（空室・管理・修繕・保険を引いた77%換算）。
A と B の返済差は年間で約115〜175万円ある。
つまり **B・C を選んだ時点で、賃料は返済差を埋めきれない。**
「事業として買う」＝事業用ローンで買う、という意味なら、
23区で1戸賃貸の規模では**答えはノー**。棟数を増やすか、自宅であることを使うかの二択になる。

> 逆に言えば、A は「低金利・長期・団信」という住宅ローンの条件を、
> 収益を生む床にも適用できてしまう構造であり、そこが賃貸併用の唯一にして最大の旨味。

## 3. 器の設計：「自宅1/2以上」がすべてを決める

住宅ローン（フラット35を含む多くの金融機関）は、併用住宅について
**「住宅部分＝自ら居住する部分の床面積が、建物全体の1/2以上」**を要件とする。
※金融機関により「賃貸部分は融資対象外」「賃貸部分はアパートローンと組み合わせ」など扱いが分かれる。**必ず個別に確認する。**

ここから設計上の制約が自動的に決まる。

| 建物 | 1階を丸ごと貸すと | 判定 |
|---|---|---|
| 2階建て・各階同面積 | 賃貸50% / 自宅50% | **危険**。図面の実測でわずかに割れると要件を落とす |
| 2階建て・1階の一部（玄関・水回り・納戸）を自宅側に残す | 賃貸35〜45% | ○ 現実的 |
| 3階建て | 賃貸30〜35% | ◎ 最も素直 |

**設計ルール**
1. 賃貸部分は**延床の45%まで**に抑える（本リポジトリのスクリーナーもこの閾値を使用）。
2. 面積は「なんとなく半分」ではなく**確認申請図面と登記床面積で確定**させる。按分計算の根拠は税務でも使う。
3. **区分登記はしない。** 分けると住宅ローン・住宅ローン控除・住宅用地特例・売却の全部が面倒になる。
4. 賃貸戸は 20〜45㎡（1R〜1LDK）。これ以上大きくすると自宅が痩せ、出口も狭くなる。

> ⚠ **住宅ローンで買って自宅に住まず全部貸すのは契約違反。** 期限の利益喪失＝一括返済請求の対象。
> 「とりあえず住宅ローンで買って後で全部貸す」は選択肢に入れない。

## 4. 建築・法規：1階を貸すと建物の「種類」が変わる

内部で行き来できない独立住戸を作った時点で、その建物は一戸建て住宅ではなくなる。

| 形 | 建築基準法上の扱い | 規制の重さ |
|---|---|---|
| 内部で行き来できる（自分の家の一室を貸す・下宿） | 一戸建て住宅 | 軽い（ただし他人に貸す実務が難しい） |
| 各戸が**直接地上へ出られる**・共用廊下なし | **長屋** | 中。特殊建築物ではない＝**用途変更の確認申請が不要** |
| 共用廊下・共用階段がある | **共同住宅**（特殊建築物） | 重い。200㎡超で用途変更の確認申請、耐火・避難・消防の要件が上がる |

**実務上の要点**

- 1階に専用玄関を独立して設け、**長屋**として計画すると規制が一段軽くなる。設計の初手はここ。
- **界壁**：長屋・共同住宅の各戸の界壁は、遮音性能を持ち、かつ準耐火構造として小屋裏・天井裏まで達させる必要がある（法30条・令114条）。
  上下階の界床の遮音は、法規以前に**クレームと退去の最大要因**。既存戸建の改修では遮音が最も金と手間を食う。
- **用途地域**：第一種低層住居専用地域でも、住宅・長屋・共同住宅は建てられる。
  一方で**1階を店舗として貸すのは原則不可**（兼用住宅として床面積50㎡以下かつ建物の1/2未満などの要件内に限られる）。
  「1階を貸す」でも住居貸しと店舗貸しで難易度がまったく違う。
- **設備の分離**：電気・ガス・水道の**メーターを分ける**。分けないと使用量を按分請求することになり、実務が破綻する。
  水道の口径増径や引込追加が必要な場合があり、**私道の掘削承諾が取れないとここで詰む**（→ risk_guide.md 1章）。
- **消防**：用途判定（長屋か共同住宅か）で必要設備が変わる。所轄消防署で事前相談。
- **駐輪・ゴミ置場・郵便受け・表札**：賃借人の生活動線が自宅と交差しない配置にする。ここを詰めないと生活の質が落ちる。

**1階特有の論点**
浸水（内水氾濫を含む）／防犯／日照・採光／隣地からの視線／庭・専用部の管理責任。
**1階住戸は上階より賃料が下がる**（本リポジトリの試算では −7% を置いている）。

## 5. お金の構造

### 5.1 式

```
総事業費 = 物件価格 + 諸費用(価格の約7%) + 賃貸化工事費
月返済   = 元利均等（総事業費 − 自己資金、金利、期間）
手取り率 = 1 − 空室10% − 管理5% − 修繕/原状回復6% − 保険雑費2% = 77%
賃貸の手取り = 賃料 × 77% − 固都税等 × 賃貸部分の床面積比

損益分岐賃料 = (月返済 + 固都税等) × 賃貸部分の床面積比 ÷ 77%
実質の住居費 = 月返済 + 固都税等 − 賃貸の手取り
```

**見るべき数字は2つだけ。**

1. **余裕度 ＝ 想定賃料 ÷ 損益分岐賃料**。1.0を割ったら、賃貸部分は返済を賄えず自宅側の持ち出し。
2. **実質の住居費**。これを**いま払っている家賃と比べる**。それ以外の使い方をしない。

利回りで見てはいけない。自宅部分が収益を生まない以上、物件全体の利回りは定義上ずっと低く出るし、
「表面利回り◯%」は賃貸併用では意味を持たない指標になる。

### 5.2 賃貸化工事費の目安（中古戸建を改修する場合／木造・都内）

| 項目 | 目安 |
|---|---|
| 玄関の分離・外部階段 | 80〜200万円 |
| 水回り一式新設（キッチン・浴室・洗面・便所） | 200〜350万円 |
| 界壁・界床の遮音／準耐火 | 80〜200万円 |
| 電気・ガス・水道のメーター分離、引込・増径 | 50〜150万円 |
| 内装・建具・設備 | 100〜200万円 |
| 設計・確認申請（必要な場合） | 30〜100万円 |
| **合計** | **概ね550〜1,000万円** |

スクリーナーの既定値は**550万円**（下限寄り）。**見積りを取ったら必ず置き換えて再計算する。**
ここが200万円ずれると余裕度は簡単に1.0を割る。

### 5.3 感度（何で壊れるか）

| 変数 | 動かすと | 効き方 |
|---|---|---|
| 金利 +1.0% | 月返済 +約2.5万円（借入4,900万・35年） | **最も効く。** 変動で組むなら金利上昇分を自己資金で吸収できるか |
| 賃料 −10% | 手取り −約0.8万円/月 | 効くが致命的ではない |
| 空室4ヶ月 | 年間 −約40万円 | **1戸しかない＝空けば収入ゼロ。** 分散が効かないのが単室賃貸の本質的弱点 |
| 工事費 +200万円 | 月返済 +約0.6万円 | 見積り前の試算は常に楽観に振れる |
| 大規模修繕（15年目） | 100〜300万円 | 積立していないと必ず自宅家計から出る |

## 6. 実データで見た成立ライン

[hybrid.html](./hybrid.html) は、毎日自動更新される [listings.json](./data/listings.json)（23区の売出物件）に
上記モデルを当てたもの。2026-09-07 時点のスナップショットでの結果：

**母集団 1,273件 → 形として成立 31件**

| 除外理由 | 件数 |
|---|---:|
| 区分マンション（1階だけ貸す構造が作れない） | 898 |
| 価格が住宅ローンの現実的上限超 | 118 |
| 駅徒歩が遠く単身賃貸の需要が細る | 68 |
| 延床が小さく、1階を割くと自宅が成立しない | 67 |
| 再建築不可（住宅ローンが付かない） | 53 |
| 借地権（融資と転貸承諾の二重ハードル） | 33 |
| 土地で建築可能延床が不足 | 5 |

そして残った31件の中身が、この問いに対する一番正直な答えになっている。

| エリア | 例 | 価格 | 賃貸戸 | 想定賃料 | 分岐賃料 | 余裕度 | 実質住居費 |
|---|---|---:|---:|---:|---:|---:|---:|
| 江戸川区鹿骨4 | 戸建・延床86㎡ | 2,450万 | 25㎡ | 6.0万 | 3.1万 | **1.92** | **3.8万/月** |
| 葛飾区西水元6 | 戸建・延床86㎡ | 3,080万 | 37㎡ | 8.2万 | 5.7万 | **1.45** | **4.4万/月** |
| 葛飾区立石1 | 戸建・延床94㎡ | 3,500万 | 33㎡ | 7.4万 | 5.3万 | **1.40** | 6.4万/月 |
| 足立区谷在家3 | 戸建・延床109㎡ | 4,990万 | 45㎡ | 10.0万 | 8.9万 | 1.12 | 9.7万/月 |
| 世田谷区梅丘2 | 戸建・延床110㎡ | 9,580万 | 32㎡ | 10.9万 | 12.1万 | 0.90 | 24.5万/月 |
| 杉並区高井戸西1 | 戸建・延床98㎡ | 12,000万 | 44㎡ | 14.2万 | 23.4万 | **0.61** | 30.8万/月 |

**読み取れること**

1. **明確な余裕（余裕度1.2以上）があるのは外周区（江戸川・葛飾・北）の4件だけ。**
   賃料は価格ほど地域差がつかない（都心の賃料は、価格ほどには高くならない）ため、
   価格が上がるほど「賃料で返済を賄う」構造は崩れる。
   31件の余裕度の中央値は **0.90**、1.0を超えたのは12件だが、その多くは1.0ちょうど付近で拮抗している。
2. **城南・城西（世田谷・目黒・渋谷・新宿・杉並）では、1階賃貸は住居費の一部補填にしかならない。**
   それでも賃貸の手取りは月6.5〜11.5万円あり、その分だけ実質住居費が下がる（年80〜140万円）。
   「回らないからやらない」ではなく、**何のためにやるのかを言い換える**必要があるということ。
3. **土地から新築する型は、建築費が総額の過半を占めて一気に不利になる。**
   容積が余っていても「建てられる＝建てるべき」ではない。
   スクリーナーは想定延床を150㎡（自宅105＋賃貸45）で頭打ちにしている。
4. **再建築不可・借地権はここで完全に脱落する（86件）。**
   README の「安く買えるルート」の主力が、賃貸併用では使えない。
   融資が付かない物件は、賃貸併用という型と根本的に相性が悪い。

> ⚠ **想定賃料は推定値**であり、賃料の一次データではない。
> 区の実取引㎡単価から利回りを逆算した近似（`scripts/screen_hybrid.py` の `rent_per_m2`）。
> 単身向け小型住戸は㎡単価が上振れするため推定は保守側（低め）に出る。
> **判断の前に、SUUMO賃貸で同一エリア・同面積の実募集を3件以上見て置き換える。**

## 7. 税：何が経費になり、何がならないか

| 項目 | 扱い |
|---|---|
| 所得区分 | **不動産所得**。1戸なら「事業的規模（5棟10室）」ではない |
| 青色申告特別控除 | 非事業的規模では**最大10万円**（65万円は事業的規模＋複式簿記＋e-Tax等が要件） |
| 専従者給与 | 非事業的規模では**不可** |
| 経費 | 賃貸部分に**床面積按分**した分のみ。固都税・保険・修繕・管理費・借入金利息（元本は経費でない） |
| 減価償却 | **建物の賃貸部分のみ**（土地は不可）。木造住宅の法定耐用年数22年。中古は簡便法で短くなる |
| 損益通算 | 不動産所得の赤字は給与所得等と通算可。ただし**土地等の取得に係る負債利子は通算対象外** |
| 住宅ローン控除 | 家屋の**床面積の1/2以上が自己の居住用**であることが要件。控除対象は**居住用部分に対応する借入金**（按分） |
| 固定資産税 | 併用住宅は居住部分の割合で住宅用地の適用率が決まる。居住部分1/2以上なら敷地全体が住宅用地。**住宅1戸につき200㎡まで課税標準1/6**＝賃貸戸が増えると枠も増える |
| 消費税 | **住宅の貸付けは非課税**。したがって建物の消費税還付は狙えない（2020年改正で居住用賃貸建物の仕入税額控除は不可）。**店舗貸しは課税** |
| 不動産取得税・登録免許税 | 住宅の軽減は主に自己居住部分。賃貸部分の扱いは要確認 |
| 火災保険 | 賃貸部分があると「住宅物件」でなく併用扱いとなり保険料が上がる場合がある。施設賠償責任も検討 |

**実務上の一番のポイント**：按分の根拠（床面積）を**取得時に図面と登記で確定**させ、以後ずっと同じ比率で通すこと。
後から比率を動かすと税務署への説明がつかなくなる。取得の前に税理士に按分方針を確認しておく。

## 8. 出口：ここが賃貸併用の最大の弱点

**賃貸併用住宅は、売るときに買い手が2種類ともいなくなる構造を持つ。**

| 買い手 | なぜ買わないか |
|---|---|
| 実需（自分で住みたい人） | 賃貸部分が邪魔。他人が同じ建物にいるのを嫌う。価格に賃貸部分の建築費が乗っているのに使えない |
| 投資家（利回りで買う人） | 自宅部分が空床でしかない。全体を収益還元で見ると利回りが低すぎる |

結果、**査定が「取引事例（実需）」と「収益還元（投資）」のどちらでも低く出る**。
これは価格が下がる、ではなく**流動性が落ちる**（買い手が現れるまでの時間が延びる）という形で効く。

**対策（取得前に決めておくこと）**

1. **定期借家契約にする**（借地借家法38条）。普通借家だと正当事由なしに退去させられず、
   「自宅に戻す」「更地で売る」という出口が借家人の意思に縛られる。定借なら期間満了で確定終了できる。
   ※定借は普通借家より賃料が5〜10%程度下がる傾向。**流動性のために賃料を払う**という取引と理解する。
2. **単世帯に戻せる設計にしておく。** 界壁を撤去可能に、2階から1階へ内部階段を後付けできる位置に。
   「賃貸をやめて広い一戸建てとして売る」という第2の出口を物理的に残す。
3. **区分登記しない。** 一体で売れなくなる。
4. **賃貸部分を大きくしすぎない。** 45%を超えると住宅ローン要件も出口も同時に悪化する。
5. **土地の価値で出口を担保する。** 建物を評価してもらえない前提に立つと、
   結局は「土地として売れるか」＝ README/listings.html の値持ち評価に戻る。**そこが本体。**

## 9. リスク（risk_guide.md 追補）

賃貸併用に固有で、既存のリスクガイドに載っていないもの。

| リスク | 内容 | 確認先 |
|---|---|---|
| **単室集中リスク** | 1戸しかない＝空室率は0%か100%。分散が効かない。退去〜次の入居まで2〜4ヶ月は普通に空く | 地場の賃貸仲介（実際の成約期間） |
| **同居ストレス** | 音・臭い・来客・ゴミ・共用部の使い方。オーナーが同じ建物にいるため直接クレームが来る | 実際にやっている人の話 |
| **管理者としての責任** | 設備故障は深夜でも自分に来る。管理委託（賃料5%）で切り離せるかを最初に決める | 管理会社 |
| **入居者を選べないリスク** | 差別的な選別はできない。滞納・近隣トラブル時の対応を事前に決めておく | 保証会社・管理会社 |
| **1階の浸水** | 内水氾濫を含む。1階住戸は直撃。保険料・空室・退去に効く | ハザードマップ／listings.json の `hazard`・`elev` |
| **住宅ローンの用途違反** | 自宅に住まなくなった時点で契約違反。転勤等でも要届出 | 金融機関 |
| **金利上昇** | 変動で組んだ場合、返済増を賃料で吸収できない（賃料は金利に連動しない） | 自分の返済比率 |
| **賃貸部分の陳腐化** | 15年で設備は一巡。修繕を積み立てていないと自宅家計を直撃 | 見積り |
| **既存不適格** | 現況延床が容積上の建築可能床を超えている中古戸建は、増改築・用途変更で床を減らされる可能性。融資審査にも響く | 建築士・行政 |

## 10. 専門家に聞くこと（README K章の追補）

**不動産業者（地場の賃貸仲介にも）**
- この面積・この間取りの1階住戸は、いくらで、何ヶ月で埋まるか。**直近の成約事例**を見せてほしい
- 1階であることの減価はいくらか。専用庭・専用玄関は加点になるか
- 賃貸併用住宅の売却事例はあるか。何ヶ月かかったか

**建築士**
- 1階に独立住戸を切り出せるか。**長屋として計画できるか**（共同住宅にせずに済むか）
- 界壁・界床の遮音と準耐火をどう納めるか。概算は
- 用途変更の確認申請は要るか
- 自宅部分と賃貸部分の床面積比を図面上いくつにできるか
- 単世帯に戻せる設計にした場合の追加費用は

**金融機関（複数行）**
- 賃貸併用住宅に住宅ローンを出すか。**自宅部分の割合の要件は何%か**
- 賃貸部分も融資対象に含まれるか、アパートローンとの組み合わせになるか
- 賃料収入を返済比率の計算に算入してくれるか
- 団信は全額に付くか

**税理士**
- 床面積按分の方針。減価償却の取り方
- 住宅ローン控除と不動産所得の申告をどう並立させるか
- 法人化する意味があるか（この規模では通常ない、の確認）

**行政**
- 建築指導課：用途地域、長屋/共同住宅の判定、既存不適格の有無
- 消防署：用途判定と必要設備
- 水道局：口径増径・引込追加の可否と費用

## 11. 撤退条件

以下のいずれかに当たったら、賃貸併用としての検討を止める（学習用としては記録して残す）。

- 自宅部分を**延床の1/2以上**にできない／面積比を図面で確定できない
- 取扱い金融機関で**住宅ローンが出ない**（＝事業用ローンしか選べない → 2章のとおり成立しない）
- 賃貸化工事の**見積りを入れると余裕度が1.0を割る**
- 地場の賃貸仲介が「この面積・この立地では埋まらない」と言う／成約事例を出せない
- 1階が浸水想定区域内で、賃借人に説明できるリスク水準を超える
- **私道の掘削承諾が取れず**、メーター分離・水道増径ができない
- 単世帯に戻す設計上の余地がなく、出口が「賃貸併用として売る」1本しかない
- 再建築不可・借地権（そもそも入口で脱落）
- **「家賃収入で儲かる」と思って検討している**（＝住居費削減という本来の目的を見失っている）

## 12. 判定ルール（README O章の賃貸併用版）

README O章の5条件に、賃貸併用では次の2つを**追加**して、計7条件すべてを満たさない限り「買い」としない。

6. **自宅1/2以上を図面で確定でき、住宅ローンを出す金融機関を1行以上、実名で特定できている**
7. **賃貸をやめても成立する**（賃料ゼロでも返済を続けられる／単世帯に戻して売れる）

条件7が本質。**賃料をあてにしないと払えない返済額は、そもそも組んではいけない。**
1階の賃料は「あると住居費が下がるもの」であって、「ないと破綻するもの」にしてはならない。
そう設計できたときだけ、この型は強い。

## 付録：スクリーナーの使い方

```bash
# 既定パラメータ（金利1.0%・35年・自己資金600万円・賃貸化工事550万円）
python3 scripts/screen_hybrid.py

# 自分の条件に置き換えて再計算
python3 scripts/screen_hybrid.py --rate 1.6 --years 35 --equity 1200 --reno-man 800 --top 40

# 事業用ローンで組んだ場合を見る
python3 scripts/screen_hybrid.py --rate 2.8 --years 25
#   → 同じ31件で、余裕度1.0以上は 12件 → 1件、中央値は 0.90 → 0.57 に落ちる。
#     これが「事業として買う」と成立しないことの実測。
```

出力：`hybrid.html`（一覧ページ）と `data/hybrid_candidates.json`（試算データ）。
前提値はすべて `scripts/screen_hybrid.py` の `PARAMS` に集約してある。

**このスクリーナーの正しい使い方**は、上位の物件を買うことではない。
**パラメータを動かして、判断がどこで反転するかを見ること。**
金利を1%上げる、工事費を800万円にする、賃料を10%下げる——
それで消える候補は、最初から余裕がなかったということ。
