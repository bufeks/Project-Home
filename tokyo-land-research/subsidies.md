# 制度・補助金・制度の隙間（subsidies.md）

ゴール「[都心に土地を持つ](./land_strategy.md)」に対して、**公的制度で実際に効くもの**を洗い出したカタログ。

制度は**年度ごとに名称・金額・要件が変わる**。本書は「どういう枠組みがあるか」と
「どの順番で当たるか」を整理したもので、**金額と可否は必ず窓口で確認すること**。
最新情報が取れない状態で当てにして資金計画を組むと、そこが崩れる。

---

## 0. 先に：やってはいけないこと

制度を探す前に、これを固定しておく。ここを踏むと経路そのものが終わる。

| やってはいけないこと | 何が起きるか |
|---|---|
| **住宅ローンで買って自分は住まない** | 契約違反。期限の利益喪失＝一括返済請求。悪質なら詐欺 |
| 補助金の要件を満たさないまま申請する | 不正受給。返還＋加算金、公表、場合により刑事 |
| 金融機関に事実と異なる資料を出す（収入・自己資金・レントロール） | 融資取消・一括返済。以後どの金融機関からも借りられない |
| 用途地域・建築基準法に反する用途で使う | 是正命令。融資引き上げ。保険も効かない |
| 二重契約／実勢と異なる価格の契約書 | 私文書偽造・詐欺 |

> **「制度の隙間」＝合法的に用意されている枠を漏れなく使うこと。**
> 要件を満たさないのに使うことではない。ここを混同すると、5〜10年の経路が1回で消える。

---

## 1. 順番を間違えると全部無効になる

**補助金・助成金は「契約前・着工前の申請」が原則。**買ってから探しても、たいてい間に合わない。

```
① 制度を調べる（区の窓口・都・国）        ← 物件を探す前
② 対象になる物件の条件を把握する          ← 条件が物件選びの条件になる
③ 物件を探す
④ 売買契約の前に、区の窓口で「この物件は対象か」を確認
⑤ 交付申請 → 交付決定 → 契約・着工        ← この順番。逆にすると出ない
⑥ 完了報告 → 交付
```

**特に注意**
- 「着工後の申請は不可」が原則。解体・改修も同じ
- 年度予算が尽きると締め切られる（先着順の制度が多い）
- **併用不可の組み合わせが多い**（同一工事に国と都の両方は不可、など）。組み合わせは窓口で確認
- 交付決定から完了報告まで期限がある。工期が延びると失効することがある

## 2. 融資の制度 ── ここが一番効く

[land_strategy.md](./land_strategy.md) のとおり、この経路のボトルネックは**与信**。
だから制度の中でも融資関連の効き目が最も大きい。

### 2.1 日本政策金融公庫

| 項目 | 内容 |
|---|---|
| 位置づけ | 政府系。**決算実績がなくても創業段階で相談できる**のが民間との最大の違い |
| 期間 | 設備資金で最長20年程度 |
| 金利 | 固定。条件により民間の事業用ローンより低いことがある |
| 担保・保証 | 無担保・無保証の枠もある |
| 特別枠 | **女性、35歳未満、55歳以上**の創業者向けに金利優遇の枠がある |

⚠ **重要な留保**：公庫は「事業」への融資であり、**単なる資産運用としての不動産投資は対象外**と判断されることがある。
不動産賃貸業が対象になるかは事業計画の書き方と支店の判断で分かれる。
**最初にやることは、支店に事前相談して「自分のケースが対象か」を確認すること。**無料で聞ける。

> 民間の「黒字3期」の壁を、正面から回避できる可能性のある唯一のルート。
> land_strategy.md 4.3 で「与信の製造に3年かかる」と書いたが、公庫が使えるならそこが短縮される。

### 2.2 住宅金融支援機構

- **賃貸住宅融資**：子育て世帯向け・サービス付き高齢者向け住宅など、政策目的に沿う賃貸住宅への長期固定融資
- **まちづくり融資**：市街地再開発等
- **フラット35**：自己居住が要件。**賃貸には使えない**。ただし賃貸併用で自宅部分が1/2以上なら申込可（融資対象は自宅部分まで）
- **フラット35S**：省エネ・耐震・バリアフリー等の基準を満たすと当初期間の金利引下げ

### 2.3 信用保証協会

**不動産賃貸業は原則として保証対象外業種。**ただし不動産管理業など併営する事業は対象になりうる。
「事業をつくる」side で保証協会付き融資を使いたいなら、**賃貸業以外の事業の実体**が要る。

## 3. 不燃化特区・木密 ── 都心の土地に直結する

**東京都＋各区の「不燃化推進特定整備地区（不燃化特区）」。**
木造住宅密集地域の建替え・除却を促すための制度で、**都心の古家付き土地を買う戦略と正面から噛み合う**。

| メニュー | 内容 |
|---|---|
| **老朽建築物の除却（解体）費助成** | 解体費の助成。木造で坪3〜5万＝40〜80万、狭小・接道難ならさらに高い解体費が軽くなる |
| **建替えの設計費・工事監理費の助成** | 建替える場合 |
| **固定資産税・都市計画税の減免** | 建替えた場合に一定期間 |
| **専門家派遣** | 建築士・弁護士等の無料相談 |

⚠ **制度には期限があり、延長を繰り返している。**現行の期限・対象区域・要件は必ず区の窓口で確認すること。
対象は「区域内」かつ「一定の築年・構造」などの条件付き。

**このリポジトリのデータで該当するもの**

[listings.html](./listings.html) は不燃化特区・木密地域を `🌊` で分類済み。
現在**80件**が該当し、うち**都心10区の戸建・土地は27件**。

| 区 | 該当件数 | 主な地区 |
|---|---:|---|
| 新宿区 | 29 | 大久保・百人町、西新宿北側、北新宿 |
| 渋谷区 | 21 | 本町（初台・幡ヶ谷至近） |
| 世田谷区 | 7 | 北沢三・四・五丁目（下北沢近接） |
| 目黒区 | 6 | 原町一丁目 |
| 品川区 | 1 | 戸越二・四・五・六丁目 |

> **木密＝今は古家が多くて割安、将来は更新が進む地区。**
> ゴールが「5〜10年で都心の土地を持つ」なら、
> ①今は割安に買える ②解体費が助成される ③建替え後に税減免 ④地区全体の更新で価値が上がる、
> という4つが同じ方向に効く。**この経路は制度と時間軸が噛み合っている。**

## 4. 耐震関連

各区の**木造住宅耐震化助成**。対象は原則 **1981年5月31日以前**（旧耐震）の木造住宅。

| メニュー | 目安 |
|---|---|
| 耐震診断 | 無料〜一部助成の区が多い |
| 耐震改修 | 上限100〜150万円程度が多い（区により差が大きい） |
| 除却（解体）助成 | 持っている区がある |

⚠ **所有者が住んでいることを要件にする区と、賃貸でも可の区がある。**ここは区ごとに違うので必ず確認。

**都心の再建築不可・古家付き土地はほぼ旧耐震**（[land_path.html](./land_path.html) の候補を参照）。
買う前に「その区の耐震助成の対象になるか」を確認しておくと、改修費の見積りが変わる。

## 5. 空き家関連

| 制度 | 内容 |
|---|---|
| 各区の**空き家利活用助成** | 改修費の助成。**「地域貢献活用」（子育て支援・高齢者・地域交流の場）を条件**にするものが多い |
| 東京都「空き家利活用等区市町村支援事業」 | 都から区市町村への支援。実際の窓口は区 |
| 空き家バンク | 各自治体。都心23区は物件が少ない |

> **1階を地域向けのスペース（子育て・高齢者・コミュニティ）として貸すなら、
> 改修費助成の対象になりうる。**[rental_hybrid.md](./rental_hybrid.md) 4章の店舗テナントとは
> 別の選択肢として、収益は下がるが助成と地域との関係が得られる型。

### 売主側の特例を交渉材料にする

**「被相続人の居住用財産（空き家）を売ったときの3,000万円特別控除」は売主の特例。**
買主には直接効かないが、**売主には期限がある**（相続開始から一定期間内の譲渡）。

→ 相続で取得した空き家を売り出している売主は、**期限内に売りたい理由がある**。
[listings.html](./listings.html) の「相続・売り急ぎ」タグは、この文脈で読むと指値の材料になる。

## 6. 省エネ関連

国と都に複数の制度があり、**年度ごとに名称が変わる**（子育てエコホーム／GX志向型住宅／先進的窓リノベ／給湯省エネ 等）。

| レベル | 枠組み |
|---|---|
| 国 | 新築の省エネ性能、既存住宅の断熱改修（窓・断熱材・給湯器）への補助 |
| 東京都 | **東京ゼロエミ住宅**（新築の省エネ基準達成で補助。都独自） |
| 都・区 | 断熱改修、太陽光、蓄電池への助成 |

⚠ **賃貸住宅が対象になるメニューと、自己居住のみのメニューが混在する。**年度と制度ごとに違う。
2025年4月から新築住宅の省エネ基準適合が義務化されているので、**建てる場合は必ず関係する**。

## 7. 税制 ── 「住まない」場合に効くものが意外に多い

自己居住が要件のものと、そうでないものを分けて把握する。ここが制度の隙間として一番実用的。

| 制度 | 自己居住が要件か | 備考 |
|---|---|---|
| **固定資産税の住宅用地特例** | **不要** | **賃貸住宅でも適用。1戸あたり200㎡まで課税標準1/6。**戸数が増えれば枠も増える |
| **不動産取得税の1,200万円控除** | **不要** | **戸建て貸家（床面積50〜240㎡）**、共同住宅（1戸40〜240㎡）で要件を満たせば適用 |
| 登録免許税の住宅用家屋の軽減 | **必要** | 賃貸には使えない |
| 住宅ローン控除 | **必要** | 賃貸には使えない。併用住宅は居住用部分のみ按分 |
| 住宅取得等資金の贈与の非課税 | **必要** | 直系尊属から。賃貸には使えない。併用住宅なら自宅部分で按分できるか要確認 |
| 小規模宅地等の特例（相続） | 用途による | 貸付事業用宅地等 200㎡まで50%減／特定居住用 330㎡まで80%減 |
| 青色申告特別控除65万円 | 不要 | **事業的規模（5棟10室）＋複式簿記＋e-Tax** が要件。1戸なら最大10万円 |
| 中古建物の減価償却（簡便法） | 不要 | 木造で法定22年を全部経過なら**4年**で償却。節税効果は大きいが→次項 |
| 消費税の仕入税額控除 | — | 住宅貸付は非課税で控除不可。**店舗貸しなら控除の余地**（rental_hybrid.md 4.6） |
| 小規模企業共済 | 不要 | 掛金全額所得控除。**事業的規模（5棟10室）なら加入可** |

### ⚠ 減価償却の落とし穴

**中古木造を4年で償却すると税金は大きく減るが、決算が赤字になる。**
[land_strategy.md](./land_strategy.md) 4.3 のとおり、**赤字決算は次の融資を止める**。

> ゴールが「5〜10年で都心の土地」なら、**節税より与信を優先する期**を意図的に作る必要がある。
> 償却をどう取るかは、税理士に「融資を引き続けたい」という前提を伝えたうえで設計する。
> ここを税理士に伝えずに任せると、節税最適化された赤字決算が出てきて経路が止まる。

## 8. 用途を変えることで開く制度

| 型 | 制度 | 向き・不向き |
|---|---|---|
| **セーフティネット住宅**（住宅確保要配慮者向け） | 登録は**無料**。改修費補助、家賃低廉化補助、家賃債務保証料補助 | **小規模でも使える。**空室リスクの高い物件と相性がよい。専用住宅として登録すると補助が厚いが用途が縛られる |
| サービス付き高齢者向け住宅（サ高住） | 建設費補助＋機構融資＋税制優遇 | **原則10戸以上**の規模要件。小規模には合わない |
| 子育て支援型の賃貸住宅 | 国・都に整備補助のメニュー（年度による） | 設備要件（キッズスペース等）がある |
| 住宅宿泊事業（民泊） | 届出制 | **年180日上限＋各区の上乗せ条例が厳しい**（新宿・渋谷等）。用途地域制限もあり、都心では実質使いにくい |

## 9. 「土地を持つ」ことに直結する制度の隙間

補助金ではないが、**制度上の救済・特例**として使えるもの。
再建築不可を買う戦略（land_strategy.md 4.2）はここに乗る。

| 制度 | 内容 | 現実性 |
|---|---|---|
| **建築基準法43条2項2号の許可** | 接道義務を満たさない敷地の救済許可 | **個別審査・建築のたび再申請・承継の保証なし。**期待値を高く置かない |
| **位置指定道路** | 私道を築造して基準法上の道路にする | 隣接所有者の同意・幅員・築造費が要る。時間がかかる |
| **連担建築物設計制度／一団地認定（法86条）** | 隣地と一体で計画し、接道・容積を融通する | **隣地買収の代替になりうる。**5〜10年あれば交渉できる |
| **セットバック（42条2項道路）** | 中心線から2m後退で建築可になる | 有効宅地は減るが、再建築可になるなら価値は跳ねる |
| **公有地（国有地・都有地・区有地）の売却** | 透明・競争入札 | 都心の良い土地は競争が強い。狭小・変形地に検討余地（README A章） |

> **どれも「時間と交渉」が要る。**だから 5〜10年という時間軸が武器になる。
> 逆に「今すぐ」なら、これらは全部使えない。

## 10. 確認先（この順番で当たる）

| # | 窓口 | 聞くこと |
|---|---|---|
| 1 | **区の建築指導課** | 用途地域、接道・道路種別、43条許可の運用、再建築の可否 |
| 2 | **区の住宅課／まちづくり課** | 不燃化特区の対象区域・現行の期限・除却費助成、耐震助成、空き家利活用助成 |
| 3 | **日本政策金融公庫の支店** | 自分のケースが融資対象か。事業計画の書き方。金利・期間 |
| 4 | **民間金融機関 3行** | 住宅ローン／事業用ローンの条件（rental_hybrid.md 12章の4問） |
| 5 | **税理士** | 青色申告の開始、**節税と与信のトレードオフ**、減価償却の取り方、法人化の判断ライン、消費税の順番 |
| 6 | **東京都住宅政策本部** | 都の制度（ゼロエミ住宅、空き家支援、セーフティネット住宅） |
| 7 | **建築士** | 耐震・省エネ改修で助成対象になる工事内容、確認申請の要否 |

**1と2は無料で、物件を買う前に何度でも聞ける。ここを飛ばして物件を探すのが一番もったいない。**

## 11. この経路で実際に効きそうな組み合わせ

制度を並べただけでは意味がないので、[land_strategy.md](./land_strategy.md) の段階設計に当てはめる。

### Phase 1（1棟目・外周区）
- **日本政策金融公庫**に事前相談（対象になるか。なるなら与信の3年が短縮できる）
- 旧耐震の物件なら**耐震助成**（診断は無料の区が多い。改修見積りが変わる）
- 青色申告を開始。**減価償却の方針を税理士と決める（与信優先の期を作る）**

### Phase 2（与信とエクイティを積む）
- 空室が出たら**セーフティネット住宅の登録**を検討（登録無料。補助と入居確保）
- 都心の**不燃化特区の物件を定点観測**。区の窓口で対象区域と期限を確認しておく

### Phase 3（都心を取る）
- **不燃化特区内の古家付き土地**なら、除却費助成＋建替え後の税減免が乗る
- 再建築不可なら、**43条2項2号・位置指定道路・連担建築物設計制度**の可能性を建築士と行政に確認
- 建てるなら**東京ゼロエミ住宅**・省エネ補助（新築は省エネ基準適合が義務）

### 常に
- **申請は契約前・着工前。**物件を決めてから制度を探すのでは遅い
- **併用不可の組み合わせ**を窓口で確認してから資金計画に入れる
- **制度を当てにした資金計画を組まない。**出たら儲けもの、くらいの位置づけにしておく
  （年度予算切れ・要件不適合で落ちることがある）

## 免責

本書は制度の**枠組みを把握するための整理**であり、個別の適用可否を判断するものではない。
**金額・要件・期限・対象区域はすべて年度ごとに変わる。**本書の記載は2026年9月時点の一般的な枠組みの説明で、
具体的な数字は意図的に幅で書いている。

**実際に使えるかどうかは、必ず所管の窓口（区・都・国・公庫）で確認すること。**
税務の取扱いは個別事情で結論が変わるため、税理士の確認を得ること。
補助金を前提にした資金計画は、その補助金が出なかった場合でも成立するように組むこと。
