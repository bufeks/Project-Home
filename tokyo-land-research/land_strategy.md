# 都心に土地を持つ — 5〜10年の設計図（land_strategy.md）

**ゴール：都心に土地を持つ。5〜10年後でいい。手段は問わない。**

このゴールに変えると、[rental_hybrid.md](./rental_hybrid.md) で壁になっていた制約の多くが制約でなくなる。
代わりに、これまで見えていなかった制約が2つ出てくる。本書はその整理と、経路の比較。

計算は [land_path.html](./land_path.html)（`scripts/land_path.py`）で自分の数字に置き換えられる。

## 1. ゴールを変えると、何が外れて何が入るか

### 外れる制約（3つ）

1. **「そこに住む」を外す**
   → 住宅ローンの「自宅1/2以上」ルールも、年収×返済比率÷審査金利の天井も関係なくなる。
   rental_hybrid.md 3章の壁は、すべて**「住む」から来ていた**。
2. **「すぐ建てる」を外す**
   → 再建築不可・狭小地が候補に入る。都心の土地が**坪100〜200万**（相場の3〜5割）で買える。
   建物が建てられないだけで、**土地の所有権は完全に手に入る**。
3. **「今すぐ」を外す**
   → 接道改善の交渉、隣地買収、法人の決算実績づくり、エクイティの蓄積。
   どれも時間が要る打ち手が、全部使えるようになる。

### 入る制約（2つ）

1. **地価上昇との競争**（待つコスト） → 2章
2. **都心のネガティブレバレッジ**（利回りが借入コストを下回る） → 3章

## 3. 都心は「利回りで買う」場所ではない

では融資で買えばいいか。ここで2つ目の制約に当たる。

**ローン定数**（年返済額 ÷ 借入額）と、物件のNOI利回りの比較：

| ローン条件 | ローン定数 |
|---|---:|
| 住宅ローン 1.0% / 35年 | 3.39% |
| 事業用 2.0% / 30年 | 4.44% |
| 事業用 2.8% / 25年 | 5.57% |
| 事業用 3.5% / 20年 | 6.96% |

借入比率70%・事業用2.8%/25年なら、年返済は物件価格の **3.90%**。これに対して：

| 表面利回り | NOI利回り（75%換算） | 判定 |
|---:|---:|---|
| 3.5% | 2.62% | 回らない |
| 4.0% | 3.00% | 回らない |
| 4.5% | 3.38% | 回らない |
| 5.0% | 3.75% | 回らない |
| **6.0%** | **4.50%** | **回る** |
| 7.0% | 5.25% | 回る |

**都心の表面利回りは概ね3.5〜4.5%、外周区は5〜6%。**
つまり都心は借入を厚くすると**持つほど赤字**になる（ネガティブレバレッジ）。

> **都心は「利回りで買う」場所ではなく「値上がりと担保力で持つ」場所。**
> 都心を取りに行くときは、①自己資金比率を大きく上げる ②現金で買う のどちらかになる。
> そして**その自己資金は、利回りの取れる外周区で作るしかない。**

## 4. 5つの経路

| ルート | 何を諦めるか | 到達の目安 | 必要なもの | 主リスク |
|---|---|---|---|---|
| **A** 貯蓄一括 | 時間・機会 | **実質不可** | 貯蓄力のみ | 地価上昇に負ける |
| **B** 外周区で1棟持って育てる | 都心に「今」住むこと | 5〜10年（土台） | 住宅ローン＋運営 | 出口の流動性、金利上昇 |
| **C** 法人／事業の与信で買う | 手軽さ・節税 | 5〜10年 | 黒字3期の決算 | 融資引き締め、拡大途中で詰む |
| **D** 都心の再建築不可を現金で | 建替え・融資・出口 | 3〜7年 | 現金3,000〜5,500万 | 使い道と出口が狭い、接道改善が不発 |
| **E** 都心を収益物件として持つ | 「住む」こと | 5〜10年 | 自己資金3〜4割 | ネガティブレバレッジ、空室 |

**A は選択肢から落ちる**（2章）。実際の設計は **B を土台に、C で与信を作り、D か E で着地する**という組み合わせになる。

### 4.1 ルートB：外周区で「回る」1棟を持ち、育てる ← 土台

[hybrid.html](./hybrid.html) の実候補（江戸川区鹿骨4・総事業費3,172万・借入2,572万・賃貸手取り月4.4万）で、
**手取りを全額 元金に充当**した場合：

| 時点 | 物件価値 | ローン残 | エクイティ | その間の貯蓄 | 合計 |
|---:|---:|---:|---:|---:|---:|
| 5年後 | 3,053万 | 1,987万 | 1,066万 | 1,500万 | 2,566万 |
| 7年後 | 3,334万 | 1,744万 | 1,590万 | 2,100万 | 3,690万 |
| **10年後** | 3,805万 | 1,371万 | **2,433万** | 3,000万 | **5,433万** |
| 15年後 | 4,741万 | 725万 | 4,017万 | 4,500万 | 8,517万 |

**この経路が作るのは現金だけではない。**

1. **自己資金**（10年でエクイティ2,433万）
2. **賃貸業の決算実績**＝次の融資の与信（→4.3）
3. **住居費の削減**（実質月4〜5万円。差額がそのまま貯蓄に回る）

5〜10年後に都心を取りに行くとき、実際に効くのは現金より **2 と 3**。

**注意点**
- 外周区を選ぶのは「利回りが取れる」から。都心で同じことをしても3章のとおり回らない
- 賃貸併用にすると出口が狭くなる（rental_hybrid.md 10章）。**土地値が本体**という前提を崩さない
- 金利上昇は繰上返済の原資を削る。変動なら緩衝材を残す

### 4.2 ルートD：都心の再建築不可・狭小地を現金で ← 最短で「土地を持つ」

**ゴールが「持つこと」なら、この評価はこれまでと変わる。**

README の「安く買えるルート」比較表では、再建築不可は初心者リスク判定 **D（学習用）**だった。
それは**ゴールが「住む」だったから**。ゴールが「土地を持つ」なら：

| 観点 | 評価 |
|---|---|
| 土地の所有権 | **完全に手に入る**（ここがゴールそのもの） |
| 価格 | **坪100〜200万＝相場の3〜5割** |
| 融資 | 付かない → **現金が要る**（だからルートB/Cで現金を作る） |
| 建物 | 建替え不可。改修のみ |
| 出口 | 狭い（次の買主も現金） |
| **時間があると効くこと** | **接道改善の交渉**（隣地の一部買収／通路確保／位置指定道路／43条2項2号の許可）。5〜10年あれば交渉できる |

**いま実在する例**（2026-09-11時点。[land_path.html](./land_path.html) に最新の一覧）

| 所在 | 価格 | 土地 | 坪単価 | 区の相場 | 駅 |
|---|---:|---:|---:|---:|---:|
| 新宿区舟町（再建築不可） | 5,380万 | 178.6㎡（54坪） | **坪100万** | 坪361万（28%） | 徒歩3分 |
| 新宿区若松町22-12（再建築不可） | 3,980万 | 60.7㎡（18坪） | 坪217万 | 坪361万（60%） | 徒歩2分 |
| 新宿区早稲田南町（再建築不可） | 3,200万 | 55.8㎡（17坪） | 坪190万 | 坪361万（53%） | 徒歩6分 |
| 目黒区中央町1（再建築不可） | 3,100万 | 38.3㎡（12坪） | 坪268万 | 坪384万（70%） | 徒歩14分 |

新宿区舟町は「**都心に54坪の土地を5,380万で持つ**」という案件。相場なら1.9億。

⚠ **安い理由は明確**：建替えられない・融資が付かない・出口が狭い。
これは値引きではなく**リスクの値段**。手を出す前に risk_guide.md 1章と
property_checklist.md 2章（接道・道路種別・私道持分・掘削承諾）を全部埋めること。
**接道改善の見込みがゼロなら、それは「安い土地」ではなく「出られない土地」。**

### 4.3 ルートC：「まず事業をつくる」の中身 ← 与信の製造

個人の住宅ローンは **年収 × 返済比率 ÷ 審査金利** で天井が決まる（rental_hybrid.md 3.1）。
年収800万なら借入4,839万が上限で、これは都心には届かない。

**事業融資は違う土俵で審査される。**

| | 個人の住宅ローン | 事業融資（個人事業／法人） |
|---|---|---|
| 何で決まるか | **年収**と審査金利 | **物件の収益力（DSCR）＋決算実績＋自己資金** |
| 天井 | 年収で固定 | 事業が育てば上がる |
| 新規参入 | 属性さえあれば1棟目から | **新設法人には出にくい。黒字2〜3期が要る** |
| 自己資金 | 少なくても可 | **2〜3割が標準**（2018年以降の引き締め後） |

→ **黒字3期を積むのに3年かかる。だから5〜10年という時間軸がちょうど合う。**

**順序を間違えないこと**

1. **1棟目から法人にするのは、この規模ではたいてい不利。**
   設立20〜30万＋維持（税理士・均等割）年30〜50万が、小さいうちは利益を食う。
   個人で1〜2棟持って、規模が出てから法人化を検討する（目安は税理士に試算してもらう）
2. **1戸だけの賃貸は税務上「事業的規模」ではない**（5棟10室基準）。
   青色申告特別控除は最大10万円、専従者給与も使えない（rental_hybrid.md 9章）
3. ⚠ **節税と与信はトレードオフ。**
   減価償却を厚く取って赤字にすると税金は減るが、**次の融資が引けなくなる**。
   5〜10年で都心を取りに行くなら、途中の数期は**節税より黒字（与信）を優先する**局面がある。
   これを税理士と最初にすり合わせておく。**ここを外すと経路そのものが止まる。**

### 4.4 ルートE：都心を収益物件として持つ（住むのは後）

「都心に土地を持つ」を融資で達成する現実的な形。

- **土地だけ（更地）には事業融資が出にくい。**事業融資は収益から返すので、収益ゼロの更地は評価が難しい
- したがって融資で都心の土地を取るなら **①収益建物ごと買う** か **②建築費とセットで借りる（建てる前提）**
- ①なら「都心の土地」は自動的に手に入る。住むのはテナント退去後・建替え後でいい

**必要な自己資金**（事業用2.8%/25年）

| 物件価格 | 自己資金比率 | 自己資金 | 借入 | 年返済 |
|---:|---:|---:|---:|---:|
| 5,000万 | 30% | 1,500万 | 3,500万 | 195万 |
| 5,000万 | 40% | 2,000万 | 3,000万 | 167万 |
| 8,000万 | 30% | 2,400万 | 5,600万 | 312万 |
| 8,000万 | 40% | 3,200万 | 4,800万 | 267万 |
| 12,000万 | 40% | 4,800万 | 7,200万 | 401万 |

3章のとおり都心は借入70%では回らないので、**自己資金3〜4割が前提**。
ルートBの10年後（エクイティ2,433万＋貯蓄3,000万＝5,433万）なら、
**8,000〜12,000万の都心物件が射程に入る**。

## 4bis. 自分が住まなければ変わるのか

**変わる。ただし「有利になる」のではなく「別のゲームになる」。**

### 4bis.1 何が外れて、何が入るか

| | 住む（賃貸併用） | 住まない（全部貸す） |
|---|---|---|
| 融資 | **住宅ローン 1.0% / 35年・団信付き** | 事業用ローン 2.8% / 25年 |
| 住宅ローン控除 | 居住用部分に適用 | **なし** |
| 自宅1/2以上ルール | **縛られる** | 自由。全床を収益に使える |
| 経費 | 賃貸部分のみ按分 | **全額計上** |
| 固定資産税 住宅用地特例 | 適用 | **適用される**（自己居住は要件ではない） |
| 不動産取得税1,200万円控除 | 適用 | **戸建て貸家なら適用**（要件を満たせば） |
| 自分の住居費 | この物件で賄う | **別途かかり続ける** |
| 物件選び | 住環境も考える | **利回りだけで選べる** |

制度面では「住まない」ほうが自由になる項目が多い（→ [subsidies.md](./subsidies.md) 7章）。
問題は融資と住居費のほうにある。

### 4bis.2 「住む」ことの経済価値＝金利差

同じ借入額で、住宅ローンと事業用ローンの月返済を比べる。

| 借入額 | 住宅ローン 1.0%/35年 | 事業用 2.8%/25年 | 差 |
|---:|---:|---:|---:|
| 2,500万 | 月7.1万 | 月11.6万 | **月4.5万・年54万** |
| 4,000万 | 月11.3万 | 月18.6万 | 月7.3万・年87万 |
| 6,000万 | 月16.9万 | 月27.8万 | 月10.9万・年131万 |
| 8,000万 | 月22.6万 | 月37.1万 | **月14.5万・年174万** |

**この差が、住宅ローンを使えることの値段。**団信（死亡時に無借金の資産が残る）はこれに加えて付いてくる。

### 4bis.3 実データ：実需物件を買って全部貸すと回らない

[hybrid.html](./hybrid.html) の候補32件を「自分は住まず全部貸す」条件で計算し直した結果
（`scripts/screen_hybrid.py --use rentout`）。

| 物件 | 住む：実質住居費 | 住まない：物件CF | 表面利回り |
|---|---:|---:|---:|
| 江戸川区鹿骨4 | 3.8万/月 | **−0.7万/月** | 6.0% |
| 葛飾区西水元6 | 4.4万/月 | −4.5万/月 | 4.6% |
| 足立区花畑7 | 7.0万/月 | −9.2万/月 | 3.7% |
| 新宿区中落合3 | 24.7万/月 | −27.3万/月 | 3.3% |

**33件すべてでキャッシュフローがマイナス。表面利回りの中央値は2.8%。**

理由ははっきりしている。**これらは「実需（住むための家）」の価格で売られているから。**
実需の価格は取引事例で決まり、収益還元では決まらない。だから利回りが出ない。

> **住むか住まないかは「同じ物件の使い方の違い」ではない。買う物件そのものが変わる。**

### 4bis.4 だから「住まない」なら市場が変わる

- **住む** → 実需物件（戸建・土地）。武器は**住宅ローンの低金利と住居費削減**
- **住まない** → 収益物件（利回りで値付けされた市場）。武器は**利回りと事業融資**

このリポジトリの [listings.html](./listings.html) は**実需物件が中心**
（1,262件中、投資向けと分類されたのは区分マンションのみ）。
つまり **「住まない」戦略を取るなら、そもそも見に行く市場が違う**（健美家・楽待などの収益物件市場。
→ [watchlist.md](./watchlist.md)）。同じ画面で比べても答えは出ない。

### 4bis.5 判断の分かれ目：いまの家賃

「住む」ことの便益は **金利差 ＋（いまの家賃 − 実質住居費）**。
だから答えは**いまいくら家賃を払っているか**で決まる。

| いまの状況 | 向く方 |
|---|---|
| 家賃15万円前後を払っている | **住む。**金利差 年54万＋住居費削減 年120万前後＝年170万以上の差がつく |
| 社宅・実家・家賃6万以下 | **住まない**ほうが相対的に有利になりうる。ただし収益物件市場で探すこと |
| 都心に住みたいわけではない | **住む。**住む場所は利回りの取れる外周区でよく、それが Phase 1 そのもの |

**ゴールが「都心に土地を持つ」で「都心に住む」ではないなら、
外周区に住んで住宅ローンを使うのが、資本形成としては一番速い。**
これは 5章の Phase 1 と同じ結論に戻る。「住まない」という選択肢は、
**いまの住居費が十分に低い場合にだけ**優位になる。

### 4bis.6 折衷：住んで、あとから全部貸す

住宅ローンで買って住み、数年後に転居して全部賃貸に切り替える型。

- **必ず金融機関に届け出る。**黙って貸すのは契約違反（→ [subsidies.md](./subsidies.md) 0章）
- 多くの金融機関は、転勤等の合理的な理由なら**賃貸に出すことを承諾する**（金利が事業用に切り替わる場合もある）
- 住宅ローン控除は**居住しなくなった年から適用外**
- 「最初から貸すつもりで住宅ローンを組む」のは契約違反。**結果としてそうなったかどうかが分かれ目**

この型は制度的にはグレーではなく白黒がはっきりしている。**届け出れば白、黙れば黒。**

## 5. 推奨する組み立て（5〜10年）

### Phase 1（0〜1年）：土台を作る
- 外周区で「回る」1棟目を取得。[hybrid.html](./hybrid.html) の余裕度1.2以上（現在は江戸川・葛飾・北の4件）
- **住居費を月4〜6万円に下げる**。差額を全額 貯蓄・繰上返済に回す
- **青色申告を開始**。ここから決算の実績が積み上がる
- 都心の再建築不可・狭小地の**定点観測を始める**（watchlist.md に追加）

### Phase 2（1〜4年）：与信とエクイティを積む
- 賃料手取りを繰上返済（期間短縮型）に。ただし修繕・空室の備えを先に積む
- **黒字決算を3期。**節税より与信を優先する期を作る（税理士と方針を決めておく）
- 金融機関3行と関係を作る。事業融資の条件（金利・期間・自己資金割合・DSCR）を毎年聞いて記録する
- 都心の候補について、接道・私道持分・隣地の状況を**現地で**調べ続ける

### Phase 3（4〜7年）：分岐点
エクイティ1,500〜2,500万＋貯蓄。ここで2つに分かれる。

- **分岐X：都心の再建築不可・狭小地を現金で取る**（ルートD）
  → 「都心に土地を持つ」を先に達成する。建物の使い道は後で考える。
  接道改善の交渉を10年かけてやる
- **分岐Y：事業融資で都心の収益物件を自己資金3〜4割で取る**（ルートE）
  → 土地は収益建物ごと手に入る。住むのは建替え後

**どちらを選ぶかは、Phase 2 の間に「都心の再建築不可で、接道改善の現実的な筋が見える物件」が
実際に出てくるかどうかで決まる。**出てこなければ分岐Y。

### Phase 4（7〜10年）：着地
- 接道改善の交渉／建替え／自宅化
- または収益物件の建替えで自宅部分を作る

## 6. 見直し・撤退の条件

| 段階 | 見直す条件 |
|---|---|
| Phase 1 | 余裕度1.2以上の1棟目が見つからない／住居費が下がらない → 時期をずらす。**無理に買わない** |
| Phase 2 | 3期目に黒字が作れない／金融機関が事業融資の条件を提示しない → ルートCは断念、DかEに一本化 |
| Phase 2 | 金利が上昇して繰上返済の原資が消える → 繰上をやめて手元流動性を優先 |
| Phase 3 分岐X | 接道改善の筋がゼロ（隣地に交渉余地なし・43条許可の見込みなし） → **買わない。**出られない土地になる |
| Phase 3 分岐Y | 自己資金3割を積んでも年返済がNOIを超える → 物件を落とすかエリアを落とす |
| 全段階 | **節税を優先して赤字決算にしてしまった** → 与信が止まる。方針を戻すのに2〜3年かかる |
| 全段階 | 「都心に土地を持つ」が目的化して、**採算の合わない物件を掴もうとしている** → 一度止める |

## 7. いま確認すること（順番）

1. **1棟目の候補を絞る** — [hybrid.html](./hybrid.html) で余裕度1.2以上。現地で通行量・周辺賃料を確認
2. **金融機関3行に事前審査** — 住宅ローンの条件（rental_hybrid.md 12章の4問）
3. **税理士に方針をすり合わせ** — 青色申告の開始、節税と与信のトレードオフ、法人化の判断ライン
4. **都心の定点観測を始める** — 再建築不可・狭小地。価格ではなく**接道の状況**を見る
5. **区の窓口2つに行く（無料）** — 建築指導課（用途地域・接道・43条許可の運用）と
   住宅課／まちづくり課（不燃化特区の対象区域と期限・除却費助成・耐震助成）。
   **物件を探す前に行く。**制度の条件がそのまま物件選びの条件になる（→ [subsidies.md](./subsidies.md)）
6. **日本政策金融公庫に事前相談** — 自分のケースが融資対象か。対象なら「黒字3期」の壁が短縮できる
7. **自分の数字で経路を再計算** — `python3 scripts/land_path.py --equity <自己資金> --save <年間貯蓄>`

**この順番が重要。**物件を先に探すと、経路の設計が物件に引きずられる。

## 付録：シミュレータの使い方

```bash
# 既定（自己資金1,000万・年間貯蓄300万・地価上昇4.5%）
python3 scripts/land_path.py

# 自分の数字に置き換える
python3 scripts/land_path.py --equity 2000 --save 500 --income 1200

# 地価上昇の想定を変えて、待つコストの感度を見る
python3 scripts/land_path.py --growth 2.0
python3 scripts/land_path.py --growth 6.0

# 自分が住まず全部貸す場合を計算する（住宅ローンが使えない代わりに全床が収益）
python3 scripts/screen_hybrid.py --use rentout --own-rent 15

# 1棟目の条件を変える（hybrid.html の別候補で置き換える）
python3 scripts/land_path.py --b-price 3080 --b-loan 3246 --b-net 5.4
```

出力：`land_path.html` と `data/land_path.json`。

**このシミュレータの正しい使い方**は、到達年を当てにいくことではない。
**地価上昇率を2%と6%で振ってみて、それでも変わらない結論だけを信じること。**
「貯蓄だけでは届かない」と「都心は借入を厚くすると回らない」の2つは、
かなり広い前提の範囲で成立する。それ以外は前提次第で動く。
